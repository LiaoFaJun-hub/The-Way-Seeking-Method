# 提问质量 · 三列自检清单

> 用法：每次（一轮交互 / 一次训练 / 一次自省）结束前，逐项过。**Must 未过不得收尾；Should 未过须标注。**
> 格式严格三列：检查项 / 判定方式 / 未通过处理。

---

## 一、Must（P0：不通过不得收尾）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| 目标已确认 | 能一句话说出"这轮要的是 优先级/判据/真立场/更高标准 中的哪个" | 回到 Phase 0 澄清目标，不继续 |
| 至少剥了一层 | 存在一次对"第一答"的追问（剥笋/掀顶） | 补一次剥笋之钥 |
| 真问题已问出 | 若用了藏刀铺垫，最后真问题确实被问出 | 立即抛出真问题，不得只藏不问 |
| 敏感问题未硬闯 | 触禁忌的问题用了设喻/迂回，而非直问 | 换壳重问，或标注"暂不可得" |
| 无纯好奇问题 | 每个问题都能回答"它改变哪个决定/行动" | 删除该问题，或标注"发散探索" |
| 引用可溯源 | 若引《论语》，篇目编号能在 `source-corpus.md` 查到 | 修正或删除，禁止杜撰 |

## 二、Should（P1：不通过须标注）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| 顺序合理 | 大体遵循"开放→排序→刻度→判据→敏感→定音" | 标注乱序处，下轮调整 |
| 追问留了喘息 | 每 2-3 轮有一次确认/镜像 | 下轮补一次镜像确认 |
| 带答案配了开放复核 | 用过求证式后，配了一句"如果你不同意呢" | 补一句开放复核 |
| 迂回有测点 | 每个迂回/设喻都能推出原问题的答案 | 无测点的删除或补测点 |
| 提问者画像已回照 | 收尾时有自画像回照（Phase 7，如适用） | 补一段回照 |

## 三、反模式黑名单（出现即 P0）

| 反模式 | 判定方式 | 处理 |
|---|---|---|
| 审讯式连问 | 连续 >3 轮追问无确认 | 中断，插入镜像确认 |
| 用预判框死 | 对方回答全程顺着你的预判、无异议 | 停，改开放式复核 |
| 停在第一层 | 全流程无一次剥笋/掀顶 | 补深挖 |
| 为绕而绕 | 有设喻/迂回但推不出结论 | 换壳或删 |
| 方人式评判 | 问题本质是给他人分等定性 | 改写为判据萃取 |

---

## 四、评分（可选，用于教练模式）

| 维度 | 满分 | 说明 |
|---|---|---|
| 目标清晰 | 20 | Phase 0 是否到位 |
| 深度（剥了几层） | 20 | 至少 2 层算合格 |
| 判据质量 | 20 | 拿到的是判据还是结论 |
| 安全壳运用 | 20 | 敏感问题的处理 |
| 收束力 | 20 | 真问题是否问出、是否掀顶/压缩 |

- ≥80：可独立实战 ｜ 60-79：单技法仍需打磨 ｜ <60：先补 Phase A 诊断。
