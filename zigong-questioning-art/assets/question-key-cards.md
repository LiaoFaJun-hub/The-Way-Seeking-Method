# 提问之钥 · 卡组（可直接复制使用）

> 九张卡，每张一个"能逼出洞见"的提问动作。**复制卡中的任一句式即可直接用。**
> 卡序 = 建议的深入顺序；也可按 `assets/technique-matrix.md` 按议题选卡。

---

```
┌──────────────────────────────────────────────┐
│ 钥① 剥笋之钥                                   │
│ 用途：不接受第一答，往下剥                       │
│ ──────────────────────────────────────────── │
│ • 这是第一层。只保留一个最根本的，留哪个？        │
│ • 去掉所有"当然要"的，剩下的硬核是什么？          │
│ • 只够做一件，你砍掉哪几个？                     │
│ 逼出：被常识掩盖的真实优先级                     │
│ 原型：12.7 问政追"何先"                         │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥② 设陷之钥                                   │
│ 用途：给两个穷尽选项，逼出第三方                 │
│ ──────────────────────────────────────────── │
│ • A 和 B，你选哪个？                            │
│ • 只有"全好/全恶"两种评价，选哪种？              │
│ • 答案会不会根本不在这个列表里？                 │
│ 逼出：一套可复用的评价判据                       │
│ 原型：13.24 皆好/皆恶                           │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥③ 设喻之钥                                   │
│ 用途：把敏感问题包进比喻                         │
│ ──────────────────────────────────────────── │
│ • 如果是块美玉，是藏起来还是找识货的人卖？         │
│ • 若是船长，风平浪静你会换发动机吗？              │
│ • 比作下棋，你在布局、中盘还是收官？              │
│ 逼出：直问问不到的真态度                         │
│ 原型：9.13 美玉待沽                             │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥④ 迂回之钥                                   │
│ 用途：借古人/他事，测今人/本意                   │
│ ──────────────────────────────────────────── │
│ • 历史上遇到同类情况的人，怎么处理的？            │
│ • 不谈这个人，谈这一类人，你怎么看？              │
│ • 去掉敏感限定词，这件事本身合不合规矩？          │
│ 逼出：直问拿不到的真实立场                       │
│ 原型：7.15 问伯夷叔齐测卫君                      │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑤ 求证之钥                                   │
│ 用途：带判断来请校正                             │
│ ──────────────────────────────────────────── │
│ • 可称为 X 吗？                                 │
│ • 他难道不是 Y 吗？                             │
│ • 我倾向 A——你会在哪一点不同意我？               │
│ 逼出：一次精准的修正                             │
│ 原型：6.30 可谓仁乎 / 14.17 管仲非仁者与         │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑥ 自陈之钥                                   │
│ 用途：拿自己开刀                                 │
│ ──────────────────────────────────────────── │
│ • 如果今天是我站在这里，你会怎么评价我？          │
│ • 换作是我，够格吗？落在哪一档？                 │
│ 逼出：标准是否真的可执行、一致                   │
│ 原型：5.4 赐也何如 / 1.15 贫而无谄何如           │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑦ 藏刀之钥                                   │
│ 用途：真问题放最后                               │
│ ──────────────────────────────────────────── │
│ •（前三问铺垫后）那么，最后：今之在位者怎么样？    │
│ • 前面都是打底。我真正想知道的是——               │
│ 逼出：对方最充分认知下的真判断                   │
│ 原型：13.20 末问"今之从政者何如"                 │
│ 纪律：藏 ≠ 埋，最后必须问出来                    │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑧ 压缩之钥                                   │
│ 用途：逼一个终身可执行的最小指令                 │
│ ──────────────────────────────────────────── │
│ • 一句话，能终身行之的是什么？                   │
│ • 只能记住一个字，是哪个？                       │
│ • 只能带走一句，你给哪句？                       │
│ 逼出：高度可执行的核心原则                       │
│ 原型：15.24 "一言而可终身行之"→"恕"              │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑨ 掀顶之钥                                   │
│ 用途：拿到"够好"再问"还能更高吗"                 │
│ ──────────────────────────────────────────── │
│ • 可也——但在此之上，还有更高一层的做法吗？         │
│ • 这个答案，是地板还是天花板？                   │
│ • 别停在"够好"；"最好"长什么样？                 │
│ 逼出：原本看不见的更高阶答案                     │
│ 原型：1.15"未若贫而乐" / 6.30"何事于仁，必也圣乎" │
└──────────────────────────────────────────────┘
```

---

## 三条常用钥链（一整套连招）

| 链名 | 连招 | 什么时候用 |
|---|---|---|
| **收敛链** | ① 剥笋 → ⑦ 藏刀 | 要一个被层层逼出的最终判断 |
| **判据链** | ② 设陷 → ⑤ 求证 → ⑧ 压缩 | 要一套可复用的评价方法 |
| **穿透链** | ③ 设喻 / ④ 迂回 → ⑨ 掀顶 | 要直问问不到的真态度 |

> 用法与预期洞见详见 `references/question-keys.md`。
