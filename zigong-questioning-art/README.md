# zigong-questioning-art · 子贡之问（门「求」）

> **一句话主张**：一个人问什么、怎么问，比他答什么更能说明他是谁。
> 不是问题模板库，而是**提问的功夫**——一套可训练的思维习惯 + 判断力 + 一组能逼出洞见的提问动作。

---

## 这是什么

从《论语》中子贡的提问艺术提炼出的**提问流派**。子贡是孔门最会问的人，孔子许多最锋利的命题（"民无信不立""过犹不及""己所不欲，勿施于人"）都是被子贡一问再问问出来的。

本技能教你/让 AI：**不接受第一个答案，把答案逼到更深一层。**

## 三种形态

| 形态 | 谁在问 | 场景 |
|---|---|---|
| **交互模式**（主） | Agent 如子贡 | 需求澄清、深度访谈、尽调、研究、决策、复盘 |
| **教练模式** | 人学技法 | 训练提问力、诊断提问风格 |
| **自省模式** | 用提问照自己 | "提问即自画像" |

## 核心内核

- **核心理念**：问判据不问定义 / 不接受第一个答案 / 在都正确的东西间问排序 / 问刻度不问标签 / 敏感问题包安全壳 / 端着判断来请校准 / 提问即自画像。
- **九钥族**：剥笋、设陷、设喻、迂回、求证、自陈、藏刀、压缩、掀顶。
- **七思维模型**：排序 / 刻度 / 天花板 / 判据 / 安全壳 / 名实落差 / 自画像。
- **三层递进链 SOP**：开放 → 封闭排序 → 启发刻度 → 敏感迂回。

## 边界

问是**求**不是攻；可带判断求证，但每带一次答案须配一次开放复核，避免用预判框死对方。
