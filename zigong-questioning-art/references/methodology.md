# 五大关键方法论

> 技法（`nine-techniques.md`）是"单招"，方法论是"成套打法"。**当你面对一个完整任务（访谈一人、研究一事、澄清一需求）时，用这五套方法论串联技法与钥族。**

---

## 方法论一：三层递进链（主编排骨架）

这是子贡整套提问路径的还原，也是现代深度访谈、尽职调查的提问路径：

```
先开放（问政式：广泛收集素材）
   ↓
再封闭排序（三选一 / 二选一：逼出优先级）
   ↓
再启发刻度（"敢问其次"：建尺子）
   ↓
最后敏感问题委婉问（设喻 / 迂回：取真话）
```

- **子贡同构**："先开放（问政）→ 再封闭排序（三选一、二选一）→ 再启发式（敢问其次）→ 最后敏感问题委婉问（当政者何如）。"
- **为什么这样排**：认知负荷从低到高，信任从浅到深。先开放建立共同语言，后敏感才不会触发防御。
- **落地**：这条链就是 `sop-interactive.md` 主干（Phase 2→5）。

## 方法论二：剥笋四问法（把答案榨到底）

对同一个目标答案，连问四层：

| 层 | 问题 | 目的 |
|---|---|---|
| 第 1 问 | "是什么/有哪些？" | 拿到公开答案 |
| 第 2 问 | "如果只能留一个，留哪个？" | 逼出优先级（排序模型） |
| 第 3 问 | "在此之上还有更高的吗？" | 掀天花板（天花板模型） |
| 第 4 问 | "一句话/一个字概括，是什么？" | 提炼内核（压缩之钥） |

- **子贡原型**：12.7 剥政 → 13.20 剥士 → 15.24 压成"恕"。
- **停止条件**：当对方开始重复、或开始说"这就是最根本的了"——此时第 4 问收束。
- **陷阱**：四问不是四轮盘问，同一轮里可以用追问衔接，节奏要顺。

## 方法论三：天花板掀翻法（专治"够好了"）

**触发**：出现"可也""差不多""够用""这样就行"。

**三步**：
1. **确认地板**："你说的这个，我理解为达到 X 就算合格，对吗？"
2. **掀顶**："那 X 之上呢？如果 X 是及格线，满分长什么样？"
3. **定位**："你现在是在地板、中间，还是已经接近天花板？"

- **子贡原型**：1.15（"未若贫而乐，富而好礼"）、6.30（"何事于仁，必也圣乎"）、11.16（"过犹不及"）——孔子三次掀顶。
- **心法**：掀顶不是否定对方，是**把对方从"评判者"拉向"修行者"**（子贡的纠偏线）。

## 方法论四：判据萃取法（拿到能复用的标准）

**目标**：不满足于"哪个对"，要"用什么标准判断对"。

**三步**：
1. **设陷**：给出两个看似穷尽的选项，逼对方否定（两端设陷法 / 13.24）。
2. **追问依据**："你是用什么标准否掉它们的？"
3. **检验可移植性**："这个标准，用在下一个人/下一件事上，还成立吗？"

- **子贡原型**：乡人皆好/皆恶 → "不如乡人之善者好之，其不善者恶之"。
- **产出**：一条可移植的评价判据，而非一次性结论。
- **检验**：好判据的标志是——换一个案例仍能用。

---

## 方法论五：安全壳包裹四步（问到难问之处）

**目标**：把直问会碰壁的问题，包进安全外壳，取回真话。

**四步**：
1. **识别敏感点**：这个问题的禁忌在哪？（立场/身份/礼法/面子）
2. **选壳**：换主体（今人→古人；自己→他人）或换载体（直述→设喻）。
3. **发问**：用设喻之钥或迂回之钥抛出。
4. **反推**：从对方的回应，反推原问题的答案；必要时再补一个"怨乎？/然后呢？"确认。

- **子贡原型**：9.13 美玉（换载体）；7.15 伯夷叔齐（换主体）。
- **验收**：壳够安全（对方愿答）+ 反推够准（你能从答案反推原问题）。
- **反例**：为绕而绕、绕完推不出结论 = 壳失败了。

## 五套方法论怎么协同

以"给一个陌生客户做尽职访谈"为例：

```
三层递进链（主编排）
  ├─ Phase 开放：广泛问（不用技法）
  ├─ Phase 排序：思想实验法（"三者只能留一"）
  ├─ Phase 刻度：剥笋四问法（建标准尺）
  ├─ Phase 判据：判据萃取法（问怎么判断合作方可靠）
  └─ Phase 敏感：安全壳包裹四步（问真实诉求/底线）
        └─ 收束：天花板掀翻法（"在此之上你还想要什么"）
```

- **协同原则**：递进链管顺序，其余四套管局部深度；天花板掀翻法可随时插入（发现"够好了"就掀）。
- **完整步骤**见 `sop-interactive.md`；**避坑**见 `pitfalls.md`。
