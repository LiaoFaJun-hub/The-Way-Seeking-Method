# yangming-questioning-art · 阳明之问（门「还」）

> **一句话主张**：**他不回答问题，他把问题还给你。**
> "圣人之道，吾性自足，不假外求"——**给答案，等于承认你缺；还问题，才是承认你本有。**

---

## 这是什么

基于《传习录》《答顾东桥书》提炼出的**以问还问的答问流派**。这是五门里**唯一的"答者"视角**：《传习录》是语录体，王阳明几乎永远是"答者"。所以"阳明之问"真正的意思是——**他如何处理别人递过来的问题**。

答案：他极少正面作答，第一件事是**把问题还回去**。

## 五形态

| 形态 | 对象 | 做法 |
|---|---|---|
| **① 还问**（主） | 来问者 | 停→诊断→弹回→落到事上 |
| **② 自问** | 自己/他人困住 | 第三人称→第一人称（"我这里如何"） |
| **③ 因材** | 不同的人 | 同一问题不同答（因病而药；"两是之"） |
| **④ 自省** | 自己 | "枝枝叶叶外头寻"诊断 |
| **⑤ 论敌/质问应对** | 外部质问 | 前提爆破连珠（《答顾东桥书》式） |

## 核心内核

- **核心理念**：把问题还给你 / 答案本自具足 / 前提一错答案必错 / 先诊断这个人再开方 / 问者停在哪一层（记得→晓得→明得）/ 不给终点 / 问完必须落到事上。
- **十钥**：反问归谬、前提爆破、反问代答、截断、逼认、设喻、分层、就地取材、因病而药、拒绝终点。
- **七思维模型**：还问 / 方向 / 前提 / 层次 / 感应 / 因病而药 / 良知自有。
- **五大方法论**：还问四步法 / 因病而药法 / 分层升级法 / 感应法 / 自问转身法。

## 怎么用

- "别人来问我""我该怎么回应他的困惑""怎么开导他"
- "我卡住了想不通""总是向外求答案""怎么办"
- "同样的问题对不同的人怎么说""双方争执不下怎么处理"
- "有人质疑/指控我怎么办"
- "什么是心即理/致良知/格竹/龙场悟道"

## 边界（四条，一票否决）

1. **只答心性/成长类问题**——事实/技术性问题**直接给答案**。
2. **反假还问**——不拿反问当"答不上来"的挡箭牌。
3. **反玄学、反反智**——"良知"不是主观任性、不是不用学。
4. **反双标操纵**——"因病而药"是因材，不是看人下菜。
> 自检"适用边界检查 / 假还问检查"；**任一未过即判定不合格。**
