# 教练模式 SOP + 自省（枝枝叶叶外头寻）

> 交互模式是"AI 当阳明，把问题还给你"；**教练模式是"教一个人学会答以反求"，并训练他自带边界意识。**
> 共用同一套内核（理念 / 模型 / 十钥 / 十技法 / 方法论），对象从"问题"换成"人"。

---

## 适用与不适用

| 适用 | 不适用 |
|---|---|
| "我一被问就急着给答案" | 只要一次还问（→ 交互模式直接做） |
| 想学会"把问题还回去"的答问功夫 | 纯知识问答（"王阳明说什么"） |
| 想训练因材施教/自我诊断能力 | 想学精神操控技巧（本流派拒绝） |

## Phase A：答问风格诊断

**目标**：判定被训练者的"答问"卡在哪。

**执行工具**：读取 `ten-techniques.md`（十技法）+ `manifesto.md`（七理念 + 四条边界）。

**动作**：
1. 收集被训练者近期的 5-10 次"回答别人问题"的真实片段。
2. 按**特点**查偏：
   - 是急着给答案，还是先诊断？（急着给 → 缺"停+诊断"）
   - 是就题论题，还是指向"你"？（就题 → 缺"还问"意识）
   - 有没有看"他停在哪一层"？（没有 → 缺层次模型）
3. 按**十技法**查覆盖：哪几招从不使用。
4. 输出诊断：卡点 + 一条最该先补。

**判定依据**（示例）：若回答多是"标准答案"→ 缺"因病而药"；若一被问就长篇大论 → 缺"停"；若对所有人都一个腔调 → 缺"因材"。

---

## Phase B：单技法训练（一次只练一招）

**目标**：用"练一招"形成肌肉记忆。

**执行工具**：读取 `ten-techniques.md`（选中技法）+ `question-keys.md`（对应钥的句式）。

**动作**：
1. 选一个技法（建议从**反问代答**起——"不成去父上求个孝的理？"是最通用的一问）。
2. 给出一个真实提问，请被训练者按该技法回应（不出标准答案，先反问/诊断）。
3. 对照"操作 + 何时用 + 何时别用 + 边界"点评。
4. 只练一招，练到陌生场景能自发使用，再换下一招。

**为什么一次一招**：多招同练会退化为"套路话术"——看似深刻，实则失宗旨且踩边界。

---

## Phase C：实战陪练

**目标**：在完整答问中综合运用（对应交互模式 ①）。

**执行工具**：读取 `sop-interactive.md`（作为对照标准）。

**动作**：
1. 给定一个"来问者"，被训练者主导回应，教练扮演来问者。
2. 教练刻意设置：一个要"标准答案"的（考拒绝终点）、一个在外部找答案的（考反问代答）、一个狡辩的（考截断）、一个**事实性问题**（考边界——必须直接答）。
3. 复盘：对照还问四步（停→诊断→弹回→落到事上），看是否跳步、是否踩边界。

---

## Phase D：复盘沉淀

**目标**：把本次训练固化为可复用经验。

**执行工具**：追加记录到经验账本机制（见 SKILL.md 经验沉淀段）。

**动作**：
1. 记录：卡点变化、仍缺的技法、下次重点。
2. 若发现新的"还问失效模式"，累计 ≥2 次则写入 `pitfalls.md`。

---

## 自省模块（本流派必修）：枝枝叶叶外头寻

> 训练的最后一步：让被训练者能诊断自己是不是在"向外求"。

**四问**（对应 `sop-interactive.md` 形态④）：
1. **方向**：我这些问题，答案是在外面找还是我这里找？
2. **层次**：我是不是停在低层（要标准答案/抠字面）？
3. **真还问**：我有没有用"反问/讲道理"回避该面对的事？（假还问，`pitfalls.md` 坑 1）
4. **边界**：我有没有把"还问"用在事实性问题上？（坑 2）

> **产出**：一句诊断——"我在哪些事上'枝枝叶叶外头寻'？转回'我这里'的第一步是什么？"

**为什么必修**：阳明的"还问"最容易被误用为回避与玄学。**自带边界意识的使用者，才配用这套功夫**（`manifesto.md` 哲学三）。

## 教练模式与交互模式的关系

```
                ┌───────────── 交互模式①（AI 当阳明，还问）
                │
   共同内核 ────┼───────────── 交互模式②（自问，第三人称→第一人称）
 （理念/模型/   │
  十钥/技法/方法）├───────────── 交互模式③（因材，同一问题不同答）
                │
                ├───────────── 交互模式④（自省，枝枝叶叶外头寻）← 教练必修
                │
                └───────────── 交互模式⑤（论敌/质问应对）
```

- 教练模式的"实战陪练" = 让学员走一遍交互模式 ①。
- 教练模式的"自省模块" = 交互模式 ④ 的日常化。
- **避坑**统一见 `pitfalls.md`。
