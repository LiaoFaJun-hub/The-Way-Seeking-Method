# 阳明之问 · 以问还问的答问流派

> **一句话主张**：**他不回答问题，他把问题还给你。** 前三家都在往外求一个东西（尺、破绽、刀、场），阳明的问法，是把你从外面拉回来——**"给答案，等于承认你缺；还问题，才是承认你本有。"**
>
> **这是系列第五把刀，也是唯一的"答者"**：《传习录》是语录体，阳明几乎永远是"答者"。"阳明之问"真正的意思是——**他如何处理别人递过来的问题**。
>
> **⚠️ 本流派内置四条适用边界（不可拆）**：
> 1. **只答心性/成长类问题**——事实/技术性问题**直接给答案**
> 2. **反假还问**——不拿反问当"答不上来"的挡箭牌
> 3. **反玄学、反反智**——"良知"不是主观任性、不是不用学
> 4. **反双标操纵**——"因病而药"是因材，不是看人下菜

## 触发词

- **回应他人**："别人来问我""我该怎么回应他的困惑""怎么开导他""怎么让他自己想明白"
- **自问转向**："我卡住了想不通""总是向外求答案""不知道该怎么办""换个角度"
- **因材/争执**："同样的问题对不同的人怎么说""怎么因材施教""双方争执不下怎么处理"
- **自省**："我是不是老在向外求""枝枝叶叶外头寻""怎么自省"
- **论敌应对**："有人质疑/指控我""替对立立场辩护怎么应对""怎么驳倒这个诘问"
- **知识解读**："什么是心即理""致良知怎么理解""知行合一""格竹是什么""龙场悟道"
- **排除**：事实/技术性问题（直接答）；用反问回避作答；精神操控；心理治疗。

## 调用者

- **Agent 主控**：识别到用户意图属于上述六类时自动加载本技能。
- **用户直接调用**：说"用阳明之问""心学问答""以问还问""答以反求"时加载。
- **不调用场景**：纯事实检索、技术操作指导、纯情绪陪伴——这些不应"还问"（尤其事实问题，见边界一）。

## 设计哲学（流派宣言·速览）

读全篇见 `references/manifesto.md`。三条：

1. **从"给答案"到"还问题"（结构性反转）**——把对方递来的问题，翻转成对方自己的功课。
2. **一人一方——法无定法，但有宗旨**——天泉证道"两是之"：不判谁对，判谁适用于谁。
3. **反问是母语，但"还问"有它的地界**——内置四条适用边界；违反任一即判定不合格。

## SOP 总览

本技能采用 **五形态路由 → Phase 推进 → 边界自检** 模式：

```
入口路由 ─┬─ ① 还问（主）      → Phase 0→1→2→3
          ├─ ② 自问（第三人称→第一人称）→ Phase Z0→Z1→Z2→Z3→Z4
          ├─ ③ 因材（同一问题不同答）→ Phase Y0→Y1→Y2→Y3→Y4
          ├─ ④ 自省（枝枝叶叶外头寻）→ Phase S0→S1→S2→S3→S4
          └─ ⑤ 论敌/质问应对   → Phase L0→L1→L2→L3→L4
                                        └→ 质量自检（含适用边界检查/假还问检查）→ 经验沉淀
```

- **五形态共用同一内核**：理念（`manifesto.md`）+ 模型（`thinking-models.md`）+ 钥（`question-keys.md`）+ 技法（`ten-techniques.md`）+ 方法论（`methodology.md`）。
- **数据传递**：Phase 0 的对象判定决定形态；诊断结果（病/层/器）注入后续选钥。
- **分支点**：入口按"来问者/困住的自己/不同的人/自省/论敌"五类路由（见详细操作步骤入口路由表）。

## 详细操作步骤

### 入口路由

根据对象判断形态。Why：五类对象的动作不同——对来问者要"还问"，对困住的自己要"转身"，对不同的人要"因材"，对自己要"自省"，对论敌要"前提爆破"；且**任何形态前都须过适用边界检查**。

| 对象 | 执行形态 | 切入 |
|------|---------|------|
| 来问者（心性/成长问题） | ① 还问（主入口） | Phase 0 |
| 困住的自己/他人 | ② 自问 | Phase Z0 |
| 一群不同的人 / 争执双方 | ③ 因材 | Phase Y0 |
| 自己的自省 | ④ 自省 | Phase S0 |
| 外部质问/指控 | ⑤ 论敌应对 | Phase L0 |
| 需求模糊（"帮我用阳明那套"但未指定） | 先澄清对象与目的 | 询问"你是要回应别人、解自己的困惑、给不同的人回应、自省，还是应对质问？" |

**前置强制**：**适用边界检查**——是心性/成长类问题吗？**不是（事实/技术类）→ 直接给答案，退出本流派。**

**执行前先查经验账本**：读取经验账本（见经验沉淀段）最近记录——若同类任务在历史上有高频踩坑，本次优先规避。Why：坑有强复发性，先查账本可把试错成本显著压低。

### Phase 0：停（不急着答）

**目标**：停住"我来告诉你"的冲动。Why：**急着给答案，等于承认对方缺**——还问的第一步是忍住。

**执行工具**：读取 `references/thinking-models.md`（还问模型）、`references/manifesto.md`（边界一）。

**步骤**：确认心性/成长类 → 不正面作答 → 输出 `[对象: 来问者] [拟用钥: …]`。

### Phase 1：诊断（他卡在哪）

**目标**：判断对方停在哪一层、有什么病、在向外还是向内。

**执行工具**：**分层之钥** / **因病而药之钥** / 方向模型——读 `references/question-keys.md`（钥⑦⑨）、`references/thinking-models.md`（模型 2/4/6）。

**步骤**：听他的话 → 辨症（好名/求速/怕难）、辨器（利根/其次）、定位层次（记得/晓得/明得）。

### Phase 2：弹回（选钥把问题还回去）

**目标**：用钥把问题还给对方。

**执行工具**：按诊断选钥——读 `references/question-keys.md`、`references/ten-techniques.md`。

**步骤**：外部找答案→③/②；卡在病/层→④/⑦；不敢认→⑤；讲不通→⑥；要标准答案→⑩。**边界**：防假还问（`pitfalls.md` 坑 2）。

### Phase 3：落到事上（收口）

**目标**：以"你准备怎么做/去体验什么"收口。

**执行工具**：还问四步法第 4 步——读 `references/methodology.md`（方法论一）。

**步骤**：问的是**体验**，不是理解——"去事上磨一磨"。

### 形态 ② 自问（Phase Z0→Z4）

识别第三人称 → 转第一人称（"圣人处此，更有何道？"）→ 等答案自现 → 就地取材 → 落到事上。详见 `references/sop-interactive.md`。

### 形态 ③ 因材（Phase Y0→Y4）

辨器 → 辨症 → 立方（一人一方）→ 两是之（若争执）→ 守宗旨。详见 `references/sop-interactive.md`。**红线**：因材 ≠ 双标操纵（坑 5）。

### 形态 ④ 自省（Phase S0→S4）

取材 → 方向检查 → 层次检查 → 真还问检查 → 产出诊断。详见 `references/sop-interactive.md`。**产出**："我在哪些事上'枝枝叶叶外头寻'？转回'我这里'的第一步是什么？"

### 形态 ⑤ 论敌/质问应对（Phase L0→L4）

识别前提 → 前提爆破连珠 → 反问归谬 → 就地取材 → 守宗旨收口。详见 `references/sop-interactive.md`。

### 收尾：质量自检

**目标**：确保本轮未越界（核心是"适用边界检查"与"假还问检查"）。

**执行工具**：逐项过 `assets/quality-checklist.md`（三列格式）。

**步骤**：Must 项未过 → 修复后重检；**适用边界检查 / 假还问检查任一未过 → 判定不合格**（一票否决）。

## 错误处理

| 异常 | 检测方式 | 处理策略 | 严重性 |
|------|---------|---------|--------|
| 问题是事实/技术类 | 适用边界检查失败 | 直接给答案，退出还问（边界一） | 阻断 |
| 发现自己假还问 | 答案其实在你这里 | 立即改为正面回答（坑 2） | P0阻断 |
| 对方要明确结论/步骤 | "不给终点"被误用 | 区分：能固化的给明确答案（坑 3） | 阻断 |
| 引用查不到 | 核对 `source-corpus.md` 失败 | 删除引用或修正，禁止杜撰 | P0阻断 |
| 对象无法分类 | 入口路由失败 | 先澄清对象与目的，再路由 | 阻断 |
| 逼认/截断变味 | 对方抗拒、受伤 | 检查是否强加/PUA，改为交回本有之物（坑 6） | 降级 |
| 设喻变玄学 | 比喻让对方更糊涂 | 去掉比喻直接说（坑 7） | 降级 |
| 严重心理困扰 | 强烈自我否定/危机信号 | **停止，转专业帮助** | P0退出 |
| 轮次过多（>8 轮） | 计数 | 先做一次小结，确认是否继续 | 降级 |

## Gotcha 清单

读全篇见 `references/pitfalls.md`。每一条都附 WHY：

1. **只用"还问"，不答事实性问题**——对"怎么修/是多少"也反问。Why：心学的功夫地界是心性/成长，不是一切问题；事实问题还问是荒谬的。
2. **假还问——拿反问当"答不上来"的挡箭牌**。Why：还问的前提是答案本在提问者心里；答案在你这里而用反问回避，就是耍滑（本流派头号病）。
3. **把"不给终点"做成含糊回避**。Why："拒绝终点"针对活功夫不可固化，不是对该有明确答案的问题打太极。
4. **把"良知"做成主观任性/反智**。Why："心外无物"不是主观唯我论；良知是是非之心，不是"我怎么想都对"。
5. **因材施教变双标/操纵**。Why：因病而药是因材（对的人给对的答案），不是拿捏人心达成己意。
6. **逼认变逼服/PUA**。Why：逼认交回的是"对方本有的"，不是强加你的结论；本有 vs 强加是分界。
7. **设喻变玄学话术**。Why：设喻是为让对方一眼看懂，不是制造玄奥；比喻代替论证即退化为话术。
8. **忘记"落到事上"**。Why：阳明"问的是体验"；只还问不落事上，等于把活功夫变成口头禅。
9. **把"人人有圣人"变成自我优越**。Why："人有圣人"是平视不是俯视；带着优越感还问，是"自埋倒了"的另一种形式。

## 经验沉淀（每次运行建议执行）

**目标**：把本次的新发现固化为可复用经验，形成飞轮。Why：本流派的价值随"踩坑库"的厚度增长——跳过沉淀，永远停在出厂水平。

**执行步骤**：
1. 向经验账本**追加**一行（append-only，禁止覆盖历史）：日期 / 形态 / 对象类型 / 结果 / TOP踩坑 / 疑似新坑 / 状态。
2. 检查升格：本次"疑似新坑"若历史累计 ≥2 次 → 写入 `references/pitfalls.md`（附表现+WHY+破解），并在账本标注"已升格"。
3. 无新发现也要记录该行（"疑似新坑"列写"无"）——运行频次是账本的校准数据。

> 经验账本文件：初始不存在时，首次运行按上述表头创建。当前版本账本存放于 `references/pitfalls.md` 文末的"升格记录"处（或由使用者指定路径）。

## 铁律

- ❌ 禁止对事实性/技术性问题"还问"——这类问题必须直接给答案（适用边界一）
- ❌ 禁止假还问——不得用反问回避本该正面回答的问题（本流派头号病）
- ❌ 禁止把"不给终点"做成含糊回避——能固化成明确答案的问题必须给明确答案
- ❌ 禁止把"良知"做成主观任性/反智——良知的底线是"知是非"（"你心还能知是非否？"），不是"我怎么想都对"
- ❌ 禁止因材施教变双标/操纵——"因病而药"是对的人给对的答案，不是看人下菜达成己意
- ❌ 禁止逼认变逼服/PUA——交回的必须是对方"本有的"，不是强加的结论
- ❌ 禁止只还问不落事上——每次还问后必须给出"事上磨"的下一步
- ❌ 禁止引用无法在 `references/source-corpus.md` 溯源的《传习录》内容——杜撰一句即摧毁流派可信度；尤忌把"心外无物"曲解为主观唯我论
- ❌ 禁止在未过"适用边界检查"或"假还问检查"前宣布完成——两查任一未过即判定不合格（一票否决）
- ✅ 每条关键约束必须能让 Agent 说出 WHERE（在哪个 Phase 落地）与 WHY（非同义反复的原因）
