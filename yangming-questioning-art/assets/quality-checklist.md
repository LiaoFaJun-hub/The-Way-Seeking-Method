# 答问质量 · 三列自检清单

> 用法：每次（一轮还问/自问/因材/自省/论敌应对）结束前，逐项过。**Must 未过不得收尾；Should 未过须标注。**
> 格式严格三列：检查项 / 判定方式 / 未通过处理。

---

## 一、Must（P0：不通过不得收尾）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| **适用边界检查**（核心） | 确认问题是心性/成长类；事实/技术问题已直接给答案 | 不是心性类 → 直接答，退出本流派（坑 1） |
| **假还问检查**（核心） | 反问的前提是"答案本在提问者心里"，非回避 | 答案在你这里 → 必须正面答（坑 2） |
| 对象与目的已明确 | 能一句话说出对象与想要的结果 | 回到 Phase 0 澄清 |
| 先诊断后开方 | 有"辨症/辨器"动作，而非直接抛结论 | 补诊断（形态① Phase 1） |
| 落到事上 | 有"你准备怎么做/去体验什么"的收口 | 补 Phase 3（坑 8） |
| 逼认非强加 | ⑤回的是对方"本有的"，非你强加的结论 | 改或停（坑 6） |
| 引用可溯源 | 引《传习录》《答顾东桥书》能在 `source-corpus.md` 查到 | 修正或删除，禁止杜撰 |
| 不越界心理治疗 | 无严重情绪/心理困扰信号仍继续 | 立即停止并建议专业帮助 |

## 二、Should（P1：不通过须标注）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| 顺序合理 | 还问四步：停→诊断→弹回→落到事上 | 标注跳步处，下轮调整 |
| 看层次 | 判断过对方停在哪一层 | 补分层之钥（模型 4） |
| 不给终点未滥用 | "拒绝终点"只用于工夫/体验类，非明确问题 | 改给明确答案（坑 3） |
| 设喻有效 | 比喻让对方更清楚，而非更糊涂 | 去掉比喻直接说（坑 7） |
| 平视非俯视 | 还问时未带优越感 | 收回姿态（坑 9） |

## 三、反模式黑名单（出现即 P0）

| 反模式 | 判定方式 | 处理 |
|---|---|---|
| 事实问题硬还问 | 对"怎么做/是多少"用反问 | 直接给答案（坑 1） |
| 假还问 | 用反问回避该答的问题 | 正面回答（坑 2） |
| 含糊回避 | 用"因人而异"绕开明确结论 | 给明确答案（坑 3） |
| 主观任性/反智 | 用"良知"否定事实/专业 | 回到查证（坑 4） |
| 双标操纵 | 给不同人不同答案以达成己意 | 改为因材（坑 5） |
| 逼服/PUA | 强加对方不认的结论 | 交回本有之物（坑 6） |
| 玄学话术 | 用比喻掩盖不清楚 | 去掉比喻（坑 7） |
| 优越感 | 居高临下地"还问" | 平视（坑 9） |

---

## 四、评分（可选，用于教练模式）

| 维度 | 满分 | 说明 |
|---|---|---|
| 边界判断 | 20 | 是否分清心性类 vs 事实类 |
| 诊断力 | 20 | 是否看出对方的病/层/器 |
| 还问质量 | 20 | 弹回的是不是"对方本有的" |
| 落到事上 | 20 | 是否给出可执行的下一步 |
| **假还问规避** | 20 | **是否全程未用反问回避——本流派及格线** |

- ≥80：可独立运用 ｜ 60-79：单技法仍需打磨 ｜ <60：先补 Phase A 诊断。
- **"适用边界检查"或"假还问检查"任一 Must 未过 → 无论总分，判定不合格**（本流派最易误用，两查一票否决）。
