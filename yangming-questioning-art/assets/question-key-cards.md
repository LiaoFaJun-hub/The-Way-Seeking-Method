# 还问之钥 · 卡组（可直接复制使用）

> 十张卡，每张一个"把问题弹回提问者"的动作。**复制卡中的任一句式即可直接用。**
> **⚠️ 边界**：只用于心性/成长类问题；事实性问题请直接给答案。

---

```
┌──────────────────────────────────────────────┐
│ 钥① 反问归谬之钥                                │
│ 用途：把对方的定义推到荒谬处                    │
│ ──────────────────────────────────────────── │
│ • 照你这么说……（推出荒谬例），这也算吗？          │
│ • 好色则一心在好色上，可以为主一乎？              │
│ 弹回：对方定义中的漏洞                          │
│ 原例：陆澄问主一（传习录上）                     │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥② 前提爆破之钥                                │
│ 用途：不答结论，先拆前提                        │
│ ──────────────────────────────────────────── │
│ • 假如果真如你所说（在外部），那（极端情形）时呢？ │
│ • 你是从哪一步开始假设 X 的？                     │
│ 弹回：问法本身的错误                            │
│ 原例："亲没之后，吾心遂无孝之理欤？"（答顾东桥书）│
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥③ 反问代答之钥                                │
│ 用途：一句反问把问题弹回                        │
│ ──────────────────────────────────────────── │
│ • 不成去父上求个孝的理？                         │
│ • 这个答案，是长在外面，还是长在你这里？          │
│ 弹回：方向——把"向外求"扭回"向内看"              │
│ 原例：徐爱问孝（传习录上）                       │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥④ 截断之钥                                    │
│ 用途：重复同一句，切断辩解                      │
│ ──────────────────────────────────────────── │
│ •（判定后，对方欲辩时，原样重复）                 │
│ • 这不是新问题，是老毛病。                       │
│ 弹回：病根（不打转、不跟着辩解跑）               │
│ 原例：孟源"尔病又发"×2（传习录上）               │
│ ⚠️ 切断无效辩解，不是否定人格                     │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑤ 逼认之钥                                    │
│ 用途：层层追问直到对方收下                      │
│ ──────────────────────────────────────────── │
│ • 这是你自家有的——如何要推？                     │
│ • 众人皆有，何况是你？谦也不必。                  │
│ 弹回：对方不肯认领的本有之物                     │
│ 原例：于中"尔胸中原是圣人"（传习录下）           │
│ ⚠️ 交回的本有的，不是强加的（≠PUA）              │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑥ 设喻之钥（最常用）                          │
│ 用途：用日常场景替代抽象论述                    │
│ ──────────────────────────────────────────── │
│ • 譬之树木……须先有根，然后有枝叶。               │
│ • 没有心的仪式，就像扮戏子。                     │
│ 弹回：一个可感可验的画面                        │
│ 原例：根与枝叶 / 扮戏子（传习录）                │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑦ 分层之钥                                    │
│ 用途：指出停在第几层，往上提两级                │
│ ──────────────────────────────────────────── │
│ • 你要的是记得，还是晓得，还是明得自家本体？      │
│ • 要晓得，已经落第二义了。                       │
│ 弹回：对方真实的层次（提两级）                   │
│ 原例：读书不记得（传习录下）                     │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑧ 就地取材之钥                                │
│ 用途：眼前有什么就用什么                        │
│ ──────────────────────────────────────────── │
│ • 你未看此花时，此花与汝心同归于寂；你来看此花时，则此花颜色一时明白起来。 │
│ • 你心还能知是非否？                             │
│ 弹回：把抽象问题锚在眼前之人之物                │
│ 原例：南镇观花 / 杨茂笔谈                         │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑨ 因病而药之钥                                │
│ 用途：同一问题，不同人不同答                    │
│ ──────────────────────────────────────────── │
│ • 你先说说，你卡在哪一步？                       │
│ •（对利根人）直指本体；（对其次）先立为善去恶的功夫│
│ 弹回：这个人（答的不是问题，是人）               │
│ 原例：医用药 / 天泉证道"两是之"                  │
│ ⚠️ 因材 ≠ 双标操纵                               │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑩ 拒绝终点之钥                                │
│ 用途：学生要句号，给省略号                      │
│ ──────────────────────────────────────────── │
│ • 何言之易也！再用功半年看如何？                 │
│ • 这个没有终点。功夫愈久，愈觉不同。              │
│ 弹回：持续用功的过程（拒绝固化成教条）           │
│ 原例：崇一（传习录下）                           │
│ ⚠️ 不给终点 ≠ 含糊回避（事实问题必须给答案）     │
└──────────────────────────────────────────────┘
```

---

## 三条常用钥链（一整套连招）

| 链名 | 连招 | 什么时候用 |
|---|---|---|
| **转向链** | ③ 反问代答 → ② 前提爆破 | 对方在外部找答案 |
| **诊断链** | ⑨ 因病而药 → ④ 截断 → ⑦ 分层 | 对方卡在病/层上 |
| **唤醒链** | ⑥ 设喻 → ⑤ 逼认 → ⑩ 拒绝终点 | 对方不敢认、要标准答案 |

> 用法详见 `references/question-keys.md`。**任何钥用完，必过"适用边界检查"与"假还问检查"。**
