## A. 子思其人（奠基事实）

| 项 | 内容 |
|---|---|
| 姓名 | 子思，名孔伋，字子思 |
| 身份 | 孔子之孙（孔子之子孔鲤之子）；曾子的弟子 |
| 生卒 | 约公元前483年—前402年（一说享年八十二，一说六十二，"年六十二"见《史记》） |
| 经历 | 曾困于宋、居于卫；一生仕途不顺；培养出孟子（孟子受业于子思之门人） |
| 传承 | 上承孔子、曾子，下启孟子——构成"**思孟学派**" |
| 地位 | 儒学从孔子向孟子过渡的关键枢纽（"匿名的枢纽"） |
| 史料 | 《史记·孔子世家》仅数十字带过："孔子生鲤，字伯鱼……伯鱼生伋，字子思，年六十二。尝困于宋。子思作《中庸》。" |

## B. 思孟学派与荀子的批评（关键旁证）

- **"思孟学派"由荀子《非十二子》首次提出**，将子思与孟子并列批评。
- 荀子原文："略法先王而不知其统，犹然而材剧志大，闻见杂博。案往旧造说，谓之五行。"
- **意义**：这一批评反而印证子思的独特地位——他有开创性的哲学建构（尤其是"五行"学说与《中庸》的"诚"论）。

## C. 《五行》其书（出土与定位）

| 项 | 内容 |
|---|---|
| 出土 | 1993 年，湖北荆门郭店一号楚墓出土竹简，其中《五行》篇发现震惊学界 |
| 年代 | 约战国中期（公元前300年左右），是目前所见最早的《五行》文本 |
| 旁证 | 马王堆汉墓亦出土帛书《五行》，两者内容基本一致 |
| 地位 | 子思学派的核心文献；首次系统提出"仁义礼智圣"五行说 |

## D. 核心概念：仁义礼智圣（五德定义）

《五行》所说的"五行"**不是金木水火土的物质五行，而是五种德性**：

| 德 | 源材料定义 |
|---|---|
| 仁 | 爱人、恻隐，是最基础的德 |
| 义 | 宜也，恰当、公正 |
| 礼 | 规范、秩序，外在形式 |
| 智 | 明辨、通达 |
| 圣 | 最高境界，通达天道；"圣"是"五行之所和"，是道德修养的顶点 |

## E. 形于内 / 不形于内（本流派第一命题）

**原文**："仁形于内谓之德之行，不形于内谓之行。"

- **形于内**：德性真正内化于心中，成为自觉的道德品质。
- **不形于内**：德性只是外在表现，未真正内化。
- **意义**：同样的行为，可能因为内在状态不同而有本质差异。这是子思学派对儒家心性论的开创性贡献。

## F. 慎独

**原文**："君子慎其独也。"

- 不是简单的"独处时谨慎"，而是**在内心独知之处保持警醒，真诚地面对自己的内在状态**。这是道德修养的关键功夫。

## G. 五行说的哲学架构

### 层级结构（源材料原图）

```
圣（最高：通达天道）
↑
智（明辨是非）
↑
礼（规范秩序）
↑
义（公正适宜）
↑
仁（爱人恻隐，基础）
```

- 关系："仁是基础，义是仁的恰当化，礼是义的外化，智是礼的明察，圣是智的通达。每一德都以前一德为基础，又共同指向'圣'的圆融境界。"
- **警告**："这个结构不是机械的阶梯。"——用于定位与指路，不用于排序与鄙视。

### 天人关系
- 主张**天人相通**；道德修养最终要**"与天地合其德"**；从内在德性出发，逐步向外扩展，达到与天道相通的境界。

### 与《中庸》的呼应
- 《中庸》讲"**诚**"——"诚者，天之道也；诚之者，人之道也。"诚是"形于内"的极致。
- 《中庸》"**天命之谓性，率性之谓道，修道之谓教**"与《五行》修养路径一致：天性→循性而行→修养教化。
- 《中庸》"君子慎其独也"与《五行》慎独一脉相承，并进一步深化为"**致中和**"：喜怒哀乐未发之时保持中正，已发之后保持适度。

## H. 现代启示（源材料四条）

1. **从"形于内"看真实的道德**：很多行为是"不形于内"的（守规矩怕罚、做好事因有摄像头）。真正的道德不是表演，是内化。
2. **从"慎独"看自我诚实**：在没人看见的地方你是什么样，你才是真正的什么样。
3. **从"圣"的境界看人格成长**：不只做"好人"（仁），而是追求与更大的整体相通（圣）。
4. **从"诚"看内外一致**：真正的成长，是让内在与外在统一起来。

## I. 慎独的现代诠释（源材料三条）

1. **在没有人看见的地方**：慎独的核心是无人监督时依然保持道德自觉——不是压抑，而是**高级的自律**。
2. **从"不敢"到"不愿"**：从"怕被发现"到"内心不接受"——道德发展从**他律到自律**的关键跃迁。
3. **从"表演"到"真实"**：审视自己的道德行为，有多少是"形于内"的真实，有多少是"不形于内"的表演。
