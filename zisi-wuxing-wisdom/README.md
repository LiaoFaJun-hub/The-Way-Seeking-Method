# zisi-wuxing-wisdom · 子思五行（门「照」）

> **一句话主张**：同样的行为外壳之下，可能是完全不同的内在状态——真正的成长，是从"不形于内"到"形于内"，从"不敢"到"不愿"，从"表演"到"真实"。
> 这不是道德评分工具，是**照见内在状态的功夫**。

---

## 这是什么

基于子思（孔伋）学派的《五行》（1993 郭店楚简）与《中庸》，提炼出的**审德功夫流派**。核心是《五行》的判断："**仁形于内谓之德之行，不形于内谓之行**"——行为外壳一样，内在的德性状态可能天差地别。

本技能帮一个人（或一段行为）看清：这是**内化的德**，还是**外挂的表演**？

## 三种形态

| 形态 | 对象 | 场景 |
|---|---|---|
| **交互模式**（主） | 一个行为/关系/情绪/人格困惑 | 自我审察、习惯诊断、理解一个人 |
| **教练模式** | 人学自省 | 训练审德功夫 |
| **自省模式** | 用五德照自己 | "提问即自画像"式的内在反照 |

## 核心内核

- **核心理念**：形于内/不形于内 / 五德（仁义礼智圣）是层级不是标签 / 慎独 / 诚 / 从"不敢"到"不愿" / 圣境 / 中和。
- **九钥族**：形内、慎独、诚意、动机、递进、相和、圣境、中和、天人合德。
- **七思维模型**：形内 / 递进 / 慎独 / 诚 / 他律→自律 / 中和 / 天人合德。
- **形内四问法 + 五行递进诊断 SOP**。

## 边界

- 审德是**照见**不是**审判**——禁止给人贴道德标签、制造优越感。
- 五德是指路不是排名。
- 识别到严重情绪/心理困扰 → 停止审德，转专业帮助。
