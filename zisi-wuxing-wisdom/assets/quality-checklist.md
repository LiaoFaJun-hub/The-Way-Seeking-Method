# 审德质量 · 三列自检清单

> 用法：每次（一轮交互 / 一次训练 / 一次自省）结束前，逐项过。**Must 未过不得收尾；Should 未过须标注。**
> 格式严格三列：检查项 / 判定方式 / 未通过处理。

---

## 一、Must（P0：不通过不得收尾）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| 对象已明确 | 能一句话说出审察对象（行为/关系/情绪/人格/抉择） | 回到 Phase 0 澄清，不继续 |
| 外壳与内芯已分离 | Phase 1 只描述了行为、未夹带辩解 | 重做现象描述，剥离解释 |
| 形内已判定 | 给出"形于内/不形于内（或部分）"的判定 | 补形内之钥 |
| 非审判他人 | 判定对象是"我"或理解性提问，而非给他人定性 | 改为理解性提问或收回结论 |
| 无道德排名 | 未出现"你在X就不如在Y的人"类表述 | 改为"当前X、下一步Y" |
| 有下一步 | 至少给出一条可执行的最小下一步 | 补递进之钥或跃迁法第4步 |
| 引用可溯源 | 引《五行》《中庸》原句能在 `source-corpus.md` 查到 | 修正或删除，禁止杜撰 |
| 未越界心理治疗 | 无严重情绪/心理困扰信号仍继续审德 | 立即停止并建议专业帮助 |

## 二、Should（P1：不通过须标注）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| 顺序合理 | 大体遵循"描述→形内→定位→慎独→动机→升维→画像" | 标注乱序处，下轮调整 |
| 慎独有压力测试 | 用了一次无人场景检验 | 补慎独之钥 |
| 避开了自我美化 | 回答中至少有一次承认外部驱动 | 用设空场景重问 |
| 五德定位非机械化 | 允许跨德反哺，未强制逐级通关 | 修正表述 |
| 画像只描述不评判 | 收尾画像无褒贬定性词 | 重写为描述性语言 |
| 诚未误作宣泄 | 未鼓励"和盘托出" | 引中和之钥修正 |

## 三、反模式黑名单（出现即 P0）

| 反模式 | 判定方式 | 处理 |
|---|---|---|
| 审判他人 | 用"你这是不形于内"否定别人 | 改为自我指向或理解性提问 |
| 五德排名/优越感 | 用五德制造鄙视链 | 收回，改"指路"表述 |
| 表演式慎独 | 每次回答都在自我美化 | 用形内四问法分离行为与辩解 |
| 只诊断不开方 | 有结论无下一步 | 补最小下一步 |
| 越界治疗 | 情绪危机中继续审德 | 立即停止，转专业帮助 |
| 道德绑架 | 用古义要求他人苦修/贬低自我关怀 | 回到"是否更真实、更自主、更通" |

---

## 四、评分（可选，用于教练模式）

| 维度 | 满分 | 说明 |
|---|---|---|
| 对象清晰 | 20 | Phase 0 是否到位 |
| 形内判定准 | 20 | 是否分清外壳/内芯 |
| 定位有据 | 20 | 五德定位是否落到具体卡点 |
| 真实度检验 | 20 | 慎独/动机是否绕过美化 |
| 收束有力 | 20 | 是否给出下一步/画像 |

- ≥80：可独立自省 ｜ 60-79：单钥仍需打磨 ｜ <60：先补 Phase A 诊断。
