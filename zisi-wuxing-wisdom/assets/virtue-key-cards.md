# 审德之钥 · 卡组（可直接复制使用）

> 九张卡，每张一个"能看穿行为内芯"的审察动作。**复制卡中的任一句式即可直接用。**
> 卡序 = 建议的审察顺序；也可按 `assets/virtue-matrix.md` 按场景选卡。

---

```
┌──────────────────────────────────────────────┐
│ 钥① 形内之钥                                   │
│ 用途：分清外壳与内芯                           │
│ ──────────────────────────────────────────── │
│ • 做这件事，是从心里愿意，还是从外面要求？        │
│ • 没人要求、没有回报，还做吗？                   │
│ • 这更像"德之行"，还是只是"行"？                 │
│ 照见：行为的真实性质                           │
│ 原句："仁形于内谓之德之行，不形于内谓之行。"     │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥② 慎独之钥                                   │
│ 用途：无人处压力测试                           │
│ ──────────────────────────────────────────── │
│ • 没人知道、也永远没后果，你还会做吗？           │
│ • 独处时的你，和台上的你，是同一个人吗？          │
│ • 最不愿被人看见的那个选择，是什么？             │
│ 照见：真实与表演的分界线                       │
│ 原句："君子慎其独也。"                         │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥③ 诚意之钥                                   │
│ 用途：量内外裂隙                               │
│ ──────────────────────────────────────────── │
│ • 你对外的样子，和自己知道的样子，差多少？        │
│ • 有哪件事，你希望别人以为是因为A，其实是B？      │
│ • 若你藏起来的动机都被公开，你还是同一个人吗？     │
│ 照见：内外裂隙的位置与大小                     │
│ 原句："诚者，天之道也；诚之者，人之道也。"       │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥④ 动机之钥                                   │
│ 用途：判他律还是自律                           │
│ ──────────────────────────────────────────── │
│ • 你是"不敢"，还是"不愿"？                      │
│ • 惩罚和监督都撤销，你还做（或不做）吗？          │
│ • 现在驱动你的，是怕后果，还是自己过不去？        │
│ 照见：行为的驱动力来源（外驱/内驱）              │
│ 原型："从'不敢'到'不愿'"                       │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑤ 递进之钥                                   │
│ 用途：定位当前德、下一德                       │
│ ──────────────────────────────────────────── │
│ • 你停在"仁"（有善意），还是到"义"（做恰当）？    │
│ • 你的规范（礼）是理解后建的，还是照搬的？        │
│ • 从当前这一德，往上一德的下一步是什么？          │
│ 照见：当前德性位置 + 下一阶台阶                 │
│ 原型：仁→义→礼→智→圣 层级结构                  │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑥ 相和之钥                                   │
│ 用途：查五德协调与偏缺                         │
│ ──────────────────────────────────────────── │
│ • 你"仁"很足，但"义"够吗？会不会老好人？          │
│ • 你"礼"很重，但"仁"（温度）在里面吗？            │
│ • 五德里，你最陌生的是哪一个？                   │
│ 照见：五德配置的均衡度与短板                   │
│ 原型："圣"是"五行之所和"                        │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑦ 圣境之钥                                   │
│ 用途：掀"好人"的天花板                         │
│ ──────────────────────────────────────────── │
│ • 你在做"好人"（仁），还是追求与更大整体相通（圣）？│
│ • 若"好人"只是地板，"圣"长什么样？               │
│ • 你的成长，是往"更会做人"，还是往"更通"？        │
│ 照见：成长天花板在哪、还能往哪升                 │
│ 原型：圣=通达天道、与万物合一                    │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑧ 中和之钥                                   │
│ 用途：审情绪的中与和                           │
│ ──────────────────────────────────────────── │
│ • 事情发生前，你的底色是中正平静的，还是带情绪？    │
│ • 情绪发出来后，是适度，还是过了？               │
│ • 让你失和的，是事情本身，还是没安顿好的"中"？     │
│ 照见：情绪中的失中、失和及其调理                 │
│ 原句：《中庸》"致中和"                          │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑨ 天人合德之钥                               │
│ 用途：问成长是否指向更大整体                    │
│ ──────────────────────────────────────────── │
│ • 这件事，是指向与更大整体相通，还是只围着自己转？  │
│ • 把"我"放大到与万物相关，这件事还成立吗？        │
│ • 十年后回看，它让你更"通"，还是更"小"？           │
│ 照见：成长是否指向与更大整体的相通               │
│ 原句："与天地合其德"                            │
└──────────────────────────────────────────────┘
```

## 三条常用钥链（一整套连招）

| 链名 | 连招 | 什么时候用 |
|---|---|---|
| **真伪链** | ① 形内 → ② 慎独 → ④ 动机 | 判定一个行为/德性真不真 |
| **定位链** | ⑤ 递进 → ⑥ 相和 → ⑦ 圣境 | 判断一个人卡在哪、下一步往哪 |
| **一致链** | ③ 诚意 → ⑧ 中和 → ⑨ 天人合德 | 检查内外/情绪/方向的统一 |

> 用法与照见详见 `references/virtue-keys.md`。
