# questioning-arts-hub · 提问五门 · 统一索引入口

> **问法有五门——求、照、取、拆、还。** 本技能负责**判断你该进哪一门**，并给出五家对照与协同；具体技法在各门内部。

---

## 这是什么

一个**路由入口**（不是技法本身）。当你面对"提问/对话/沟通/审察/决断/应答"类任务、不确定用哪套方法时，它帮你：

1. 先分流：**纯事实/技术问题 → 直接答，不进任何门**；
2. 判"关系"（对外求真深 / 对己看内在 / 对外逼选证 / 对局拆决断 / 对问还回去）；
3. 路由到对应的独立技能；
4. 复杂任务给出**多门协同序列**。

## 五门速记

| 门 | 人 | 一句话 | 技能 |
|---|---|---|---|
| **求** | 子贡 | 把答案逼到更深一层（激发洞见） | `zigong-questioning-art` |
| **照** | 子思 | 看行为的"形于内"（内在审察） | `zisi-wuxing-wisdom` |
| **取** | 墨子 | 把对方从"说得漂亮"拖到"不得不选" | `mozi-questioning-art` |
| **拆** | 商韩 | 拆前提、逼决断、识真伪（带警绳） | `shanghan-questioning-art` |
| **还** | 阳明 | 不回答问题，把问题还给你 | `yangming-questioning-art` |

## 怎么用

- 直接问："我该用哪种提问方法？""帮我选一把刀""这五家有什么区别？"
- 或描述任务（"我要访谈一个人""我要说服一个犹豫的老板""别人来问我怎么回应"），本入口自动路由。
- 拿不准时看 `assets/decision-card.md` 顺着箭头走。

示例输出：
```
[关系: 对外·逼选证] [入门: 取] → 加载 mozi-questioning-art
理由：你要的是让对方认账并行动，不是更深的答案（那是"求"）。
```

## 内置规则

- 纯事实/技术问题**不进任何门**，直接给答案。
- 路由后必须**加载对应技能**，不只报门名。
- 随门传达各门的**边界**：拆门"取消辩=取消纠错"、还门"事实问题不还问"等。

## 五门协同（部分）

| 场景 | 序列 |
|---|---|
| 深度访谈 | 求 → 照 |
| 说服犹豫的决策者 | 还 → 取 → 拆 |
| 拆流行说法 | 拆 → 取 |
| 自省 | 照 → 还 → 求 |

> 完整对照与协同见 `references/five-families-compare.md`、`references/selecting-guide.md`。
