# 交互模式详细 SOP（四形态）

> **本模式是流派主入口。** Agent 采取墨子"以问取证"的姿态，把对方从"说得漂亮"逼到"不得不选"。
> 本技能含**四个子 SOP**：① 论辩说服（主）② 引导自答 ③ 语言卫生自省 ④ 说服君王（加强）。
> 主干采用 **三表验问 + 察类明故 + 以取验名 + 迁行收口**（`methodology.md`）。每步标注**工具绑定**与**读取文件**——无工具绑定即视为行为漂移。

---

## 形态路由表

| 形态 | 对象 | 争什么 | 出口 |
|---|---|---|---|
| ① 论辩说服（主） | 论敌 | 立场能否自洽 | 逼出一个"取" |
| ② 引导自答 | 任何人 | 让对方自己说出结论 | 对方自答 |
| ③ 语言卫生自省 | 自己 | 自己的话真不真 | 删掉荡口/空话 |
| ④ 说服君王（加强） | 决策者/上位者 | 一件事做不做 | 落到一个决定 |

> 不确定走哪个 → 先问用户："你要驳一个人、让一个人自己开窍、检查自己的话，还是说服一个决策者？"

# 形态 ①：论辩说服（主入口）

## Phase 0：识别对象与目的（不可跳过）

**做什么**：判断对手类型（论敌/君王/弟子/自己人）与你要争的到底是什么（立场自洽？一件事做不做？行不行？判据？），并明确目的正当性。

**执行工具**：读取 `thinking-models.md`（对号入座）、`assets/technique-matrix.md`（对象→技法）。

**动作**：
1. 一句话确认目标："我们要争的不是'谁对'，是 X（立场能否自洽 / 一件事做不做）。"
2. **目的正当性自检**（`manifesto.md` 理念 7）：问这个问题，是为了兴利除害，还是为了赢？若只为赢 → 停，或降级为"帮对方看清"。

**输出**：`[对象: 论敌] [争点: {立场自洽}] [主线钥: {立信/破论/揭因}]`

**异常**：若目的纯为逞口舌 → 转入 `pitfalls.md` 坑 1 检查，拒绝抬杠。

## Phase 1：请君入瓮（锁定对方立场）

**做什么**：逼对方先亮出原则/立场，把它变成武器。

**执行工具**：**设诱之钥** / 设诱请君入瓮（读 `question-keys.md` 钥②、`eleven-techniques.md` 技法 01）。

**动作**：抛一个他必然表态的具体请求 → 提取他的原则原话 → 记下来（下一 Phase 要用）。

**墨子原型**：公输盘"吾义固不杀人"。（《公输》）

**退出条件**：拿到了对方一句可复用的原则原话。

## Phase 2：察类（同类才可相比）

**做什么**：检验双方争论对象的"类"是否相同。

**执行工具**：**知类之钥** / 察类明故法（读 `question-keys.md` 钥③、`methodology.md` 方法论二）。

**动作**：问"这俩同类吗？量变到质变了吗？"→ 若对方在小处讲理、大处不讲，用**知类递进**逐级逼到临界点。

**墨子原型**：窃桃李→攻国"此何故也？以亏人愈多"。（《非攻上》）

## Phase 3：明故（先找根，不开方）

**做什么**：追问原因，找到那个"一句话解释所有现象"的根。

**执行工具**：**假设之钥** / **还原之钥** / 明故（读 `question-keys.md` 钥⑥⑧）。

**动作**：
- 若对方给借口 → **假设之钥**揭穿（构造假设让理由失效）。
- 若对方给空话 → **还原之钥**破同语反复（"它是干什么用的？"）。

**墨子原型**："然则非为其不审也，为其寡也。"（《贵义》）；"室以为室也"。（《公孟》）

## Phase 4：归谬与自反（推回矛盾）

**做什么**：把对方命题往回推，推到自相矛盾；或把他的原则反过来用在他身上。

**执行工具**：**归谬之钥** / **自反之钥**（读 `question-keys.md` 钥④、`eleven-techniques.md` 技法 03、04）。

**动作**：不反驳结论，推前提；或问"这是你自己刚定的标准——你符合吗？"

**墨子原型**："必服非君子之服、言非君子之言，而后仁乎？"（《非儒》）；"是子之谓不扣而鸣邪？"（《公孟》）

## Phase 5：逼取（两难锁死）

**做什么**：先锁一个对方无法否认的前提，再推出两条绝路，逼他必须选。

**执行工具**：**两难之钥**（读 `question-keys.md` 钥⑦、`eleven-techniques.md` 技法 07）。

**动作**：设计真两难（两个选项都由对方立场推出）→ 抛给他 → 等他选 → 无论选哪条都暴露。

**墨子原型**："子之义将匿邪，意将以告人乎？"→"说子亦欲杀子，不说子亦欲杀子。"（《耕柱》）

**异常**：若只有一条绝路 → 说明是假两难，退回 Phase 1 重新锁定立场。

## Phase 6：迁行收口（验收，不可跳过）

**做什么**：把辩论落到一个行动/决定，验收是否"取"到。

**执行工具**：迁行收口法（读 `methodology.md` 方法论四）。

**动作**：
1. 问："这一问，改变了什么行动？逼出了什么选择？"
2. 若无 → 记"**荡口**"，回到 Phase 5 或换钥。
3. 若有 → 输出"取"的结论 + 下一步。

**墨子原型**："不足以迁行而常之，是荡口也。"（《贵义》）

# 形态 ④：说服君王（对决策者，加强）

> 特色：**只争一件事的做与不做**。不铺陈道理，只锁定一个决定。

## Phase K0：锁定唯一决定
**目标**：把话题收成一个 yes/no。工具：读 `assets/technique-matrix.md`（君王行）。
**动作**："我们今天只定一件事：做，还是不做。"若对方想谈别的 → 拉回。

## Phase K1：亮利害（三表·用之者）
**目标**：用"用之者"（实际功利）给出做/不做的最强后果。工具：三表验问法（`methodology.md` 方法论一）。
**动作**：不谈抽象对错，只谈"对国家百姓人民的利/害"。

## Phase K2：知类递进（从小事逼到大事）
**目标**：用他认同的小事，逼到当前大事。工具：**知类之钥**。
**墨子原型**：止楚攻宋——用"窃疾"逼楚王看到攻宋之荒谬。（《公输》）

## Phase K3：演示代辩（压过空谈）
**目标**：若言语无效，直接演示。工具：**演示之钥**（技法 10）。
**墨子原型**：解带为城，以牒为械，九距公输盘。（《公输》）

## Phase K4：逼取（把决定推到台面上）
**目标**：要一个明确答复。工具：**两难之钥** + **取之钥**。
**动作**："这件事，您是现在定，还是不定？"

## Phase K5：迁行（落到具体行动）
**目标**：把决定变成可执行的下一步。工具：迁行收口法。
**墨子原型**：行十日十夜至郢，派禽滑厘率三百人守宋城。

# 形态 ②：引导自答（让对方开窍）

> 特色：**不问结论，设计问题让对方自己说出来**（技法 06）。适用于教学、辅导、帮人自我发现。

- **Phase G0 找同构**：把要证明的道理，换成一个结构相同的日常场景（奉水/掺火、教耕/独耕）。工具：设问引导法（`methodology.md` 方法论五）。
- **Phase G1 问偏好**："这两者，你更看重哪个？"工具：**弃答之钥**（技法 09）。
- **Phase G2 等自答**：让对方自己说出结论——**不要抢答。**
- **Phase G3 收网**：用他的话，套回原题。
- **Phase G4 落行**：迁行收口——他准备怎么做？

**墨子原型**：巫马子"我是彼奉水者之意"（《耕柱》）；吴虑"教人耕者功多"（《鲁问》）。

# 形态 ③：语言卫生自省（查自己的话）

> 特色：用墨子的尺量**自己**的话——这是本流派最容易被忽视、也最能提升输出质量的形态。

- **Phase S0 取材**：拿出自己近期说过/写过的一段话（一段论证、一份方案、一次发言）。
- **Phase S1 名/取检查**：这段话是在说"名"还是在逼/给"取"？工具：**取之钥**（`question-keys.md` 钥①）。
- **Phase S2 空话检查**：有没有同语反复？（"因为它就是它"）工具：**还原之钥**。
- **Phase S3 荡口检查**：这段话改变了什么行动？若无 → 标"荡口"，删或改。工具：迁行收口法。
- **Phase S4 时机检查**：次序对吗？有没有"噎而穿井、死而求医"？工具：**时机之钥**。
- **产出**：一份删掉空话与荡口的"干净版"，附改动理由。

**墨子原型**：全流程锚定 A2（同语反复批判）与"荡口"红线（见 `source-corpus.md`）。

## 退出与降级

- **目的只为赢**：停，拒绝抬杠（坑 1）。
- **无法落到行**：记"荡口"，如实告知，不假装辩赢。
- **对方是价值之争**：明说"这无法用演示/功利判定"，转对话（坑 7 边界）。
- **轮次上限建议**：单次论辩建议不超过 6-8 轮；超过先做一次小结。
