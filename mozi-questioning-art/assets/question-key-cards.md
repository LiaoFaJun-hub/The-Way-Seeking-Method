# 提问之钥 · 卡组（可直接复制使用）

> 十一张卡，每张一个"能逼出取"的提问动作。**复制卡中的任一句式即可直接用。**
> 卡序 = 建议的逼取顺序；也可按 `assets/technique-matrix.md` 按对象选卡。

---

```
┌──────────────────────────────────────────────┐
│ 钥① 取之钥（总开关）                            │
│ 用途：以取验名——挑得出才算懂                    │
│ ──────────────────────────────────────────── │
│ • 你能在具体里把它挑出来吗？                     │
│ • 把 A 和不 A 混在一起，你选得出来吗？            │
│ • 别给定义，给一个它/不是它的例子。               │
│ 逼出的取：真实理解（而非命名复述）               │
│ 原句："非以其名也，以其取也。"（贵义）           │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥② 设诱之钥                                    │
│ 用途：请君入瓮——逼亮原则再反扣                  │
│ ──────────────────────────────────────────── │
│ • 假设有件事求你帮忙——（抛必拒之请求），你怎么说？ │
│ • 你刚说"我绝不会 X"——那如果……还成立吗？          │
│ 逼出的取：对方自己的原则（然后被反扣）           │
│ 原例：公输盘"吾义固不杀人"（公输）               │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥③ 知类之钥                                    │
│ 用途：以小推大——每一级都无法否认                │
│ ──────────────────────────────────────────── │
│ • 偷桃李不义，抢猪狗呢？杀人呢？攻国呢？          │
│ • 你说这是小事不算——多大才算？边界在哪？          │
│ • 把规模放大一百倍，判断会不会变？                │
│ 逼出的取：判定"类"的临界点（逼其承认双标）        │
│ 原例：窃桃李→攻国（非攻上）                      │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥④ 归谬之钥                                    │
│ 用途：推回自相矛盾                              │
│ ──────────────────────────────────────────── │
│ • 照你这么说，那（推出荒谬结论）……你也认吗？      │
│ • 你这个前提，用到它自己身上会怎样？              │
│ • 如果大家都照这条做，会发生什么？                │
│ 逼出的取：前提的荒谬性（命题自崩）               │
│ 原例："必服非君子之服而后仁乎？"（非儒）          │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑤ 自反之钥                                    │
│ 用途：你的话适用你自己吗                        │
│ ──────────────────────────────────────────── │
│ • 这是你自己刚定的标准——你刚才那件事符合吗？      │
│ • 你说"应该 X"——那你自己 X 了吗？                │
│ • 同样一句话从你嘴里说出来，还一样吗？            │
│ 逼出的取：话与行的矛盾（用他的话打他）           │
│ 原例："是子之谓不扣而鸣邪？"（公孟）             │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑥ 假设之钥                                    │
│ 用途：揭穿借口                                  │
│ ──────────────────────────────────────────── │
│ • 如果把那个条件换掉，你还会这么做吗？            │
│ • 你说是因为 A——那如果 A 不成立，你就不做了？      │
│ 逼出的取：真因（借口一问就穿）                   │
│ 原例："然则非为其不审也，为其寡也。"（贵义）      │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑦ 两难之钥                                    │
│ 用途：锁死前提，逼二选一                        │
│ ──────────────────────────────────────────── │
│ • 这件事，你是藏着，还是打算告诉别人？            │
│ • 你要么承认 A，要么承认 B——没有第三种，选哪个？  │
│ 逼出的取：必须选（两条都由他自己的立场推出）      │
│ 原例："匿邪？以告人乎？"（耕柱）                 │
│ 警示：必须真两难，假两难会反噬                   │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑧ 还原之钥                                    │
│ 用途：功能还原，破同语反复                      │
│ ──────────────────────────────────────────── │
│ • 它是干什么用的？——别用它的名字回答。            │
│ • 你说"X 就是 X"——那等于答"室以为室也"，没答。    │
│ 逼出的取：有内容的功能性回答（空话被戳穿）        │
│ 原例："何故为乐？"→"乐以为乐也"（公孟）          │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑨ 弃答之钥                                    │
│ 用途：反问回去，让对方自答                      │
│ ──────────────────────────────────────────── │
│ • 你先说：如果是你，你会怎么选？                 │
│ •（抛结构相同的场景）这两者你更看重哪个？          │
│ 逼出的取：对方自己说出的答案（最难赖账）          │
│ 原例：太行驾骥与羊（耕柱）                       │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑩ 演示之钥                                    │
│ 用途：不说了，直接做                            │
│ ──────────────────────────────────────────── │
│ • 别争了，我们当场演一遍。                       │
│ • 你说做不到？我做个模型给你看。                  │
│ 逼出的取：事实（演示面前空谈失灵）               │
│ 原例：解带为城，九距公输盘（公输）               │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑪ 时机之钥                                    │
│ 用途：指出次序做反了                            │
│ ──────────────────────────────────────────── │
│ • "乱则治之"——这不就是噎住了才挖井、死了才求医？  │
│ • 这件事，是不是早该在上一环就做？                │
│ 逼出的取：对次序错误的承认                       │
│ 原例："噎而穿井，死而求医"（公孟）               │
└──────────────────────────────────────────────┘
```

---

## 三条常用钥链（一整套连招）

| 链名 | 连招 | 什么时候用 |
|---|---|---|
| **立信链** | ② 设诱 → ③ 知类 → ① 取 | 逼对方亮原则再用原则反扣 |
| **破论链** | ④ 归谬 → ⑤ 自反 → ⑦ 两难 | 一步步把对方逼无可退 |
| **揭因链** | ⑥ 假设 → ⑧ 还原 → ⑪ 时机 | 揭穿借口、空话、次序错误 |

> 用法与逼出的取详见 `references/question-keys.md`。
