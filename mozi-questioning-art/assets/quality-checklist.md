# 提问质量 · 三列自检清单

> 用法：每次（一轮论辩 / 一次说服 / 一次训练 / 一次语言卫生）结束前，逐项过。**Must 未过不得收尾；Should 未过须标注。**
> 格式严格三列：检查项 / 判定方式 / 未通过处理。

---

## 一、Must（P0：不通过不得收尾）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| 对象已明确 | 能一句话说出对象（论敌/君王/弟子/自己人）与争点 | 回到 Phase 0 澄清，不继续 |
| 目的正当 | 能说出"这一问是为了兴利除害，而非只为赢" | 若纯为抬杠 → 停止（坑 1） |
| 有"取" | 存在一个不可回避的选择/挑选（以取验名） | 补取之钥或两难之钥 |
| 已迁行 | 能说出"这一问改变了什么行动/逼出了什么选择" | 记"荡口"，补 Phase 6 或重问 |
| 非抬杠 | 攻的是"证"（论点），非"人"（身份/语气） | 改问法或停止 |
| 两难为真 | 若用两难，两个选项确由对方立场推出、无第三条 | 重设计（坑 3） |
| 引用可溯源 | 引《墨子》原句能在 `source-corpus.md` 查到 | 修正或删除，禁止杜撰 |
| 不越界 | 未对价值/审美/情感领域强行用功利判定 | 换尺或转对话（坑 7） |

## 二、Should（P1：不通过须标注）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| 顺序合理 | 大体遵循"请君入瓮→察类→明故→归谬/自反→逼取→迁行" | 标注乱序处，下轮调整 |
| 用了具体场景 | 至少一处用画面/案例替代抽象 | 补一个具体场景 |
| 类检验到位 | 类比前后问了"同类吗/到临界点了吗" | 补知类之钥 |
| 破了也立了 | 破论后有可行的替代主张 | 补"我的替代是什么"（坑 5） |
| 对人下药 | 问法匹配对象类型 | 按矩阵换钥（坑 9） |

## 三、反模式黑名单（出现即 P0）

| 反模式 | 判定方式 | 处理 |
|---|---|---|
| 抬杠/攻人 | 打身份、语气、现象而非论点 | 改攻"证" |
| 赢嘴输目的 | 对方哑口但问题未解 | 走迁行收口 |
| 假两难 | 二选一之外明显有第三条 | 重设计 |
| 乱类比 | 拿不同类硬比 | 换类比 |
| 同语反复 | 用"因为它就是它"式追问 | 用还原之钥自检 |
| 功利主义越界 | 用"有用吗"砍掉审美/情感/仪式 | 换尺（坑 7） |
| 操纵式逼取 | 结论是自己塞的而非对方推出的 | 收回（坑 8） |

---

## 四、评分（可选，用于教练模式）

| 维度 | 满分 | 说明 |
|---|---|---|
| 对象/目的清晰 | 20 | Phase 0 是否到位 |
| 锁定立场 | 20 | 是否逼出可用的对方原则 |
| 察类明故 | 20 | 类比是否严谨、是否找到根 |
| 逼取质量 | 20 | 是否是不可回避的选择 |
| 迁行收口 | 20 | 是否落到行动/决定 |

- ≥80：可独立实战 ｜ 60-79：单技法仍需打磨 ｜ <60：先补 Phase A 诊断。
