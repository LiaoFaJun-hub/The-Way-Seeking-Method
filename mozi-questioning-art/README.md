# mozi-questioning-art · 墨子之问（门「取」）

> **一句话主张**："非以其名也，以其取也。"——你懂不懂，不看你能不能说，看你能不能取。
> 把对方从"说得漂亮"的地方，拖到"不得不拿"的地方。**每一次"取"，都是一次无法回避的暴露。**

---

## 这是什么

基于《墨子》提炼出的**以取为纲的提问/论辩流派**。墨子与子贡最大的不同：**子贡问是求，墨子问是攻**——他几乎不"请教"，全是"接招"，且必须落到行动（"不足以迁行而常之，是荡口也"）。

本技能让你/AI：**用对方自己的立场当武器，逼出一个不可回避的选择。**

## 四形态

| 形态 | 对象 | 目的 |
|---|---|---|
| **① 论辩说服**（主） | 论敌 | 争立场能否自洽 |
| **② 引导自答** | 任何人 | 让对方自己说出答案 |
| **③ 语言卫生自省** | 自己 | 查自己的话：荡口？同语反复？知类？ |
| **④ 说服君王**（加强） | 决策者 | 只争一件事做不做 |

## 核心内核

- **核心理念**：问是攻不是求 / 非以其名以其取也 / 问完必落行（否则"荡口"）/ 拿对方立场当武器 / 先找根不开方 / 具体场景 > 抽象 / 对证不对人。
- **十一钥**（honor 原文十一技法）：取、设诱、知类、归谬、自反、假设、两难、还原、弃答、演示、时机。
- **七思维模型**：取 / 类 / 故 / 自反 / 两难 / 志功 / 三表。
- **五大方法论**：三表验问法 / 察类明故法 / 以取验名法 / 迁行收口法 / 设问引导法。

## 边界

- 攻"证"不攻"人"——不得抬杠。
- 问完必须落到行，否则是"荡口"。
- **蔽于用而不知文**：这把刀专治空谈，也专杀不能兑现为效用的东西；遇审美/情感/仪式须换尺。
