# shanghan-questioning-art · 商韩之问（门「拆」）

> **一句话主张**：法家只问两句——**"你指的是哪个？"**（商鞅拆古）与**"这两个能同时成立吗？"**（韩非拆尧舜）。这两问下去，一切靠权威和惯性站着的东西都会塌。
> **最锋利，也最短命的一把刀。**

---

## 这是什么

基于《商君书·更法》与《韩非子》提炼出的**以拆为纲的提问流派**。法家是唯一把"提问"从求真工具改造成**权力技术**、并最终宣布**"提问应当消失"**的学派。

本技能让你/AI：**拆掉前提、逼出决断、识破真伪**——并自带一条不可拆的警绳。

## 四形态

| 形态 | 对象 | 目的 |
|---|---|---|
| **① 决断**（主） | 决策僵局 | 拆犹豫，逼拍板 |
| **② 拆论** | 成说/权威 | 拆前提、拆伪二难 |
| **③ 验证**（强护栏） | 可疑对象 | 识谎、尽调、识人（正当识伪） |
| **④ 自省警戒**（必过） | 自己 | 纠错空间还剩多少？ |

## 核心内核

- **核心理念**：问是拆不是求 / 判据只剩功用 / 阻力在位置不在道理 / 不做决定是最坏的决定 / 用对方崇奉的反对对方 / 提问可文体化 / 提问当消失是终局也是病灶。
- **九钥**：资格、拆古、反证、行动、对称、矛楯、折算、正问、故问。
- **七思维模型**：位阻 / 拆古 / 的彀 / 对称 / 折算 / 验证 / 无辩。
- **五大方法论**：的彀验问法 / 拆古四步 / 对称拆解法 / 效率折算法 / 自设问答文体法。

## 边界（内置警绳，一票否决）

1. **取消"辩"=取消纠错**——秦以法家赢天下，十五年而亡；商鞅车裂，韩非死于狱。
2. **验证模式仅限正当识伪**——严禁操纵、诱供、侵害。
3. **"有用吗"不是唯一的尺**——不得砍掉伦理/情感/审美。
4. **"说之难"反讽**——把一切对话当败局算的人，最后自己也被这么算。
> 自检"纠错空间检查""操纵红线检查"；**警绳项 < 12 分即判定不合格。**
