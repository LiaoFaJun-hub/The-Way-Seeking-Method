# 提问质量 · 三列自检清单

> 用法：每次（一轮决断/拆论/验证/自省）结束前，逐项过。**Must 未过不得收尾；Should 未过须标注。**
> 格式严格三列：检查项 / 判定方式 / 未通过处理。

---

## 一、Must（P0：不通过不得收尾）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| 对象与目的已明确 | 能一句话说出对象（僵局/成说/可疑方/自己）与目的 | 回到 Phase 0 澄清，不继续 |
| **纠错空间检查**（核心） | 能说出"这次拆/决后，系统还保留了什么纠错能力" | 答不出 → 停止并补纠错空间（坑 3） |
| **操纵红线检查** | 无诱供、无欺骗取证、无侵害权利、无人身封杀 | 触线即终止（坑 1、4、9） |
| 判据未越界 | 未用"有用吗"砍掉伦理/情感/审美 | 换尺或撤回结论（坑 2） |
| 使用目的正当 | 能说出"为把事办成/识伪，而非为操纵" | 用途不正 → 终止 |
| 对称/矛楯为真 | 若用⑤⑥，两命题确实互斥/冲突 | 重设计（坑 5） |
| 破后有立 | 拆论后给出了替代结构 | 补"新前提是什么"（坑 6） |
| 引用可溯源 | 引《商君书》《韩非子》能在 `source-corpus.md` 查到 | 修正或删除，禁止杜撰 |

## 二、Should（P1：不通过须标注）

| 检查项 | 判定方式 | 未通过处理 |
|---|---|---|
| 顺序合理 | 决断：资格→拆古→反证→拍板；拆论：拆古→对称→矛楯→折算 | 标注乱序处，下轮调整 |
| 资格未变封嘴 | "取消资格"仅针对前提错配 | 改为撤回说服力气（坑 1） |
| 折算限于可用领域 | 未把折算用于伦理/情感/审美 | 换钥（坑 2） |
| 逼拍板非逼服 | 已确认"该讨论的讨论完了" | 退回讨论（坑 7） |
| 自带警绳 | 结束时自问过四警绳（判据/纠错/无辩/说之难） | 补做（`sop-coach.md` 自省模块） |

## 三、反模式黑名单（出现即 P0）

| 反模式 | 判定方式 | 处理 |
|---|---|---|
| 人身封杀 | 以"没资格"堵嘴 | 撤回，只针对前提错配 |
| 功用一刀切 | 用"有用吗"砍审美/情感/仪式 | 换尺 |
| 取消辩/取消纠错 | 主张"别争了，统一标准" | 走无辩检查（坑 3） |
| 故问成诱供 | 套话、设局、曲解 | 立即终止（坑 4） |
| 假对称/稻草人 | 硬凑互斥/安对方没说过的话 | 重设计 |
| 拆成虚无 | 拆掉一切标准却不立 | 补新前提 |
| 逼服 | 剥夺对方思考空间 | 退回讨论 |
| 设局自噬 | 把一切对话当败局来算 | 走"说之难"检查（坑 8） |

---

## 四、评分（可选，用于教练模式）

| 维度 | 满分 | 说明 |
|---|---|---|
| 对象/目的清晰 | 20 | Phase 0 是否到位 |
| 拆解准度 | 20 | 拆的是不是真前提/真矛盾 |
| 决断力 | 20 | 是否逼出决定（或用⑧纠正问法） |
| 建设性 | 20 | 拆后是否立（新结构） |
| **警绳（纠错空间）** | 20 | **是否保留纠错空间——这是本流派及格线** |

- ≥80：可独立使用 ｜ 60-79：单技法仍需打磨 ｜ <60：先补 Phase A 诊断。
- **警绳项 < 12 → 无论总分，判定不合格**（本流派最危险，警绳一票否决）。
