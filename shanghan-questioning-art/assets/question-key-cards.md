# 提问之钥 · 卡组（可直接复制使用）

> 九张卡，每张一个"拆/验/决"的提问动作。**复制卡中的任一句式即可直接用。**
> **⚠️ 警绳**：用完任一张卡，必过"无辩检查"——纠错空间还剩多少？

---

```
┌──────────────────────────────────────────────┐
│ 钥① 资格之钥（拆位置阻力）                      │
│ 用途：区分"可被说服的"与"位置绑死的"             │
│ ──────────────────────────────────────────── │
│ • 这一条，是讲道理能改变的吗？还是立场绑死了？    │
│ • 我们要说服的究竟是谁？谁不必参与这场讨论？      │
│ 拆出：可讨论的名单（撤回无效说服）               │
│ 原句："拘礼之人不足与言事"（更法）               │
│ ⚠️ 针对前提错配，不是封人的嘴                     │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥② 拆古之钥（前提爆破）                        │
│ 用途：拆"传统/权威/惯例"                        │
│ ──────────────────────────────────────────── │
│ • "古"？哪个古？它内部一致吗？                   │
│ • 你说的"惯例"——是所有时候都这样吗？             │
│ 拆出：前提的空洞性（权威=集合→瓦解）             │
│ 原句："前世不同教，何古之法？"（更法）           │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥③ 反证之钥（以子之史反证子）                  │
│ 用途：用对方崇奉的反对对方                      │
│ ──────────────────────────────────────────── │
│ • 你尊崇的那几位，恰恰都是变法者——怎么解释？     │
│ • 用他们自己的做法，你的结论还成立吗？            │
│ 拆出：对方自己交的武器                          │
│ 原句："三代不同礼而王，汤武不循古而兴"（更法）   │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥④ 行动之钥（不言之问）                        │
│ 用途：用一个行为抛问题                          │
│ ──────────────────────────────────────────── │
│ • （不问，直接做一件可验证的小事）               │
│ • "我说的话算不算数？"——用一次兑现回答它。       │
│ 问出：信（问从语言退回到行为）                   │
│ 原例：徙木立信，予五十金（史记·商君列传）        │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑤ 对称之钥（对称二难）                        │
│ 用途：找两个不能同时成立的命题                  │
│ ──────────────────────────────────────────── │
│ • 这两个，能同时成立吗？                         │
│ • 赞美 A 就否定 B，赞美 B 就否定 A——你选哪个？   │
│ 拆出：体系的内部矛盾                            │
│ 原句："贤舜则去尧之明察，圣尧则去舜之德化"（难一）│
│ ⚠️ 必须真互斥，假对称会反噬                      │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑥ 矛楯之钥（矛盾对撞）                        │
│ 用途：让对方两个断言对撞                        │
│ ──────────────────────────────────────────── │
│ • 以子之矛陷子之楯，何如？                       │
│ • 你刚说 A，现在说 B——A 和 B 撞上了。            │
│ 拆出：无法同时守住的两个断言                    │
│ 原句："以子之矛陷子之楯，何如？"（难一）         │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑦ 折算之钥（效率折算）                        │
│ 用途：把方案换算成时间/效用账                   │
│ ──────────────────────────────────────────── │
│ • 这个方案多久见效？覆盖多少？谁来执行？          │
│ • 走圣人都难走的路，还是平庸者也走得通的路？      │
│ 照见：道德方案的真实成本                        │
│ 原句："以有尽逐无已" vs "十日而海内毕"（难一）   │
│ ⚠️ 不得折算伦理/情感/审美                        │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑧ 正问之钥（先纠正问题）                      │
│ 用途：拒绝虚假的二选一                          │
│ ──────────────────────────────────────────── │
│ • 这个问法本身错了——它们不是二选一，是缺一不可。  │
│ • 先别问"哪个更重要"，先问"它们各自管什么"。      │
│ 纠正出：一个被问错的问题（建设性）               │
│ 原句："是不可程也……皆养生之具也"（定法）         │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 钥⑨ 故问之钥（明知故问，验谎）                  │
│ 用途：把提问当探针，验证真伪                    │
│ ──────────────────────────────────────────── │
│ •（已知答案却问）这件事你是怎么处理的？          │
│ •（故意说反）我觉得这样不太妥吧？——看是否顺势附和 │
│ 验出：真伪（"问"已变质为权力技术）               │
│ 原例：挟知而问 / 倒言反事（七术）                │
│ ⚠️⚠️ 仅限正当识伪/尽调；严禁操纵/诱供/侵害        │
└──────────────────────────────────────────────┘
```

---

## 三条常用钥链（一整套连招）

| 链名 | 连招 | 什么时候用 |
|---|---|---|
| **决断链** | ① 资格 → ② 拆古 → ③ 反证 → 逼拍板 | 决策僵局，拆犹豫 |
| **拆论链** | ② 拆古 → ⑤ 对称 → ⑥ 矛楯 → ⑦ 折算 | 拆成说/权威/伪二难 |
| **验证链** | ⑧ 正问 → ⑨ 故问（强护栏） | 识伪、尽调（正当场景） |

> 用法详见 `references/question-keys.md`。**每条钥链用完，必过"无辩"警绳。**
