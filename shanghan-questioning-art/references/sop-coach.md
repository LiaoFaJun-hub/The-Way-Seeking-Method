# 教练模式 SOP + 自省警戒模块

> 交互模式是"AI 当商韩，拆一个场"；**教练模式是"教一个人学会以拆为纲"，并训练他自带警绳。**
> 共用同一套内核（理念 / 模型 / 九钥 / 九技法 / 方法论），对象从"场"换成"人"。

---

## 适用与不适用

| 适用 | 不适用 |
|---|---|
| "我决策总是拖着不决" | 只要一次拆论（→ 交互模式直接做） |
| "我辩论抓不住对方前提" | 纯知识问答（"韩非《问辩》说什么"） |
| 想训练批判性拆解与决断能力 | 想学操纵/诱供技巧（本流派拒绝） |

## Phase A：提问风格诊断

**目标**：判定被训练者的"拆/决"能力卡在哪。

**执行工具**：读取 `nine-techniques.md`（九技法）+ `manifesto.md`（七核心理念）。

**动作**：
1. 收集被训练者近期的 5-10 个真实决策/论证/发言。
2. 按**五特点**查偏：
   - 是在"求"、"攻"，还是在"拆"？（该拆却在求 → 缺拆解意识）
   - 判据几条？（多条但不是功用 → 或缺靶子意识）
   - 遇僵局是拖还是决？（拖 → 缺"疑行无成"）
3. 按**九技法**查覆盖：哪几招从不使用。
4. 输出诊断：卡点 + 一条最该先补。

**判定依据**（示例）：若发言多为"跟着说"→ 缺"前提爆破"与"对称拆解"；若遇决策就拖 → 缺"逼拍板"；若只会拆不会立 → 缺"纠正问题"的建设性。

---

## Phase B：单技法训练（一次只练一招）

**目标**：用"练一招"形成肌肉记忆。

**执行工具**：读取 `nine-techniques.md`（选中技法）+ `question-keys.md`（对应钥的句式）。

**动作**：
1. 选一个技法（建议从**前提爆破**起——"你指的是哪个？"是最通用的一问）。
2. 给出一个真实说法/决策，请被训练者按该技法写出 3 个问句或拆解。
3. 对照"操作 + 何时用 + 何时别用 + 警绳"点评。
4. 只练一招，练到陌生场景能自发使用，再换下一招。

**为什么一次一招**：多招同练会退化为"花架子"——看似锋利，实则每招都不实，且会忽视警绳。

---

## Phase C：实战陪练

**目标**：在完整拆论/决断中综合运用（对应交互模式 ① ②）。

**执行工具**：读取 `sop-interactive.md`（作为对照标准）。

**动作**：
1. 给定一个场景（决策僵局 / 一套成说），被训练者主导。
2. 教练刻意设置：一个位置绑死的反对者（考资格之钥）、一个拿"传统"压人的（考拆古）、一个两难（考对称）、一个"别争了"的诱惑（考无辩警绳）。
3. 复盘：对照链（资格→拆古→反证→逼拍板 / 拆古→对称→矛楯→折算），看是否拆得准、是否逼出决定、**是否保留纠错空间**。

---

## Phase D：复盘沉淀

**目标**：把本次训练固化为可复用经验。

**执行工具**：追加记录到经验账本机制（见 SKILL.md 经验沉淀段）。

**动作**：
1. 记录：卡点变化、仍缺的技法、下次重点。
2. 若发现新的"拆解失效模式"，累计 ≥2 次则写入 `pitfalls.md`。

---

## 自省警戒模块（本流派必修）

> 训练的最后一步，也是最重要的一步：**让被训练者自带警绳。**

**四问**（对应 `sop-interactive.md` 形态 ④）：
1. **判据检查**：我是不是只剩"有用吗"一条尺？（的彀模型）
2. **纠错空间检查**：我拆完/决完，系统还有没有发现"自己错了"的能力？（模型 7）
3. **无辩检查**：我是不是在追求"言无二贵，法不两适"式的统一？（秦十五年而亡）
4. **说之难检查**：我是不是把一切对话都当败局来算？（`pitfalls.md` 坑 8）

> **产出**：一句边界确认——"这次拆，我保留了什么纠错空间？"若答不出 → 本次训练未完成。

**为什么必修**：本流派是最锋利也最短命的一把刀。**只有自带警绳的使用者，才配用这套技法**（`manifesto.md` 哲学三）。

## 教练模式与交互模式的关系

```
                ┌───────────── 交互模式①（AI 当商鞅/韩非，拆场/决断）
                │
   共同内核 ────┼───────────── 交互模式②（拆论）
 （理念/模型/   │
  九钥/技法/方法）├───────────── 交互模式③（验证·强护栏）
                │
                └───────────── 交互模式④（自省警戒·必过）← 教练模式必修
```

- 教练模式的"实战陪练" = 让学员走一遍交互模式 ①/②。
- 教练模式的"自省警戒模块" = 交互模式 ④ 的日常化。
- **避坑**统一见 `pitfalls.md`。
