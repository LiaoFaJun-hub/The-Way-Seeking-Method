# 商韩之问 · 以拆为纲的提问流派

> **一句话主张**：法家只问两句——**"你指的是哪个？"**（商鞅拆古）与**"这两个能同时成立吗？"**（韩非拆尧舜）。这两问下去，一切靠权威和惯性站着的东西都会塌。
>
> **这是系列第四把刀，也是最锋利也最短命的一把**：子贡"以问**求**深"；墨子"以问取**证**"；**商韩"以问拆→验→消灭"**——法家是唯一把"提问"从求真工具改造成**权力技术**、并最终宣布**"提问应当消失"**的学派。
>
> **⚠️ 本流派自带一条不可拆的警绳**：
> 1. **取消"辩"就是取消纠错**——秦以法家赢天下，十五年而亡；商鞅车裂，韩非死于狱
> 2. **故问测试仅限正当识伪**——严禁操纵、诱供、侵害
> 3. **"有用吗"不是唯一的尺**——不得砍掉伦理/情感/审美
> 4. **说之难的反讽**——把一切对话当败局算的人，最后自己也被这么算

## 触发词

- **决断**："决策老是拖着定不下来""怎么推动拍板""怎么打破僵局""他们反对但说不动"
- **拆论**："帮我拆掉这个说法""他靠什么前提站着""怎么破这个权威/惯例""这是不是伪二选一""怎么找论证矛盾"
- **验证**："怎么识破他有没有撒谎""尽调时怎么问""怎么验证一个人靠不靠谱"
- **知识解读**："商鞅怎么变法""韩非《问辩》说什么""功用的'的彀'是什么""法家怎么提问"
- **排除**：人身封杀；诱供欺骗；用"有用吗"砍掉伦理/情感/审美；操纵式设局。

## 调用者

- **Agent 主控**：识别到用户意图属于上述四类时自动加载本技能。
- **用户直接调用**：说"用商韩之问""法家之问""以拆为纲""拆场"时加载。
- **不调用场景**：纯事实核对、纯情绪陪伴、纯内容生成——这些不需要拆解功夫（甚至会被它伤害）。

## 设计哲学（流派宣言·速览）

读全篇见 `references/manifesto.md`。三条：

1. **从"求真"到"权力技术"再到"消灭提问"**——法家的独特轨迹；本流派完整呈现这条线，**包括它的终点有多危险**。
2. **判据收敛的锋利与代价**——从墨子三表（三条）删成功用（一条），删掉的正是"众人经验"；越锋利越盲。
3. **最锋利也最短命（内置警绳）**——**取消"辩"=取消纠错**。这条警绳是本流派与前三个技能最大的不同，**不可拆**。

## SOP 总览

本技能采用 **四形态路由 → Phase 推进 → 自省警戒（必过）** 模式：

```
入口路由 ─┬─ ① 决断（主，商鞅）→ Phase 0→1→2→3→4→5
          ├─ ② 拆论（韩非）    → Phase D0→D1→D2→D3→D4→D5
          ├─ ③ 验证（强护栏）  → Phase V0→V1→V2→V3→V4→V5
          └─ ④ 自省警戒（必过）→ Phase S0→S1→S2→S3→S4→S5
                                        └→ 质量自检（三列清单，含纠错空间检查）→ 经验沉淀
```

- **四形态共用同一内核**：理念（`manifesto.md`）+ 模型（`thinking-models.md`）+ 钥（`question-keys.md`）+ 技法（`nine-techniques.md`）+ 方法论（`methodology.md`）。
- **数据传递**：Phase 0 的对象判定决定形态；各 Phase 产出汇入下一 Phase；**任何形态结束前必过 ④ 自省警戒（无辩检查）**。
- **分支点**：入口按"僵局/成说/可疑方/自己"四类路由（见详细操作步骤入口路由表）。

## 详细操作步骤

### 入口路由

根据对象判断形态。Why：四类对象的动作不同——对僵局要"逼决断"，对成说要"拆解"，对可疑方要"验真伪"，对自己要"查纠错空间"；混用会导致手段错配（尤其验证模式须强护栏）。

| 对象 | 执行形态 | 切入 |
|------|---------|------|
| 决策僵局（要拍板） | ① 决断（主入口） | Phase 0 |
| 成说/权威（要拆） | ② 拆论 | Phase D0 |
| 可疑对象（要识伪，用途正当） | ③ 验证（强护栏） | Phase V0 |
| 自己的方案/发言 | ④ 自省警戒 | Phase S0 |
| 需求模糊（"帮我用商韩那套"但未指定） | 先澄清对象与目的 | 询问"你要推动决定、拆说法、识真伪，还是检查自己？" |

**执行前先查经验账本**：读取经验账本（见经验沉淀段）最近记录——若同类任务在历史上有高频踩坑，本次优先规避。Why：坑有强复发性，先查账本可把试错成本显著压低。

### Phase 0：识别僵局与决策项（决断模式起点）

**目标**：把"要不要/要哪个"收成一个可拍板的决策项。

**执行工具**：读取 `references/thinking-models.md`、`assets/technique-matrix.md`；引用核对读 `references/source-corpus.md`。

**步骤**：一句话确认"我们要定的是 X"→ 若用户只想讨论不打算决断，转形态 ②。

### Phase 1：拆位置阻力（清场）

**目标**：区分"可被说服的"与"位置绑死的"，撤回无效说服。

**执行工具**：**资格之钥** / 取消资格——读 `references/question-keys.md`（钥①）、`references/nine-techniques.md`（技法 01）。

**步骤**：列参与者 → 标"能改变/绑死" → 对后者不再投入说服。**红线**：前提错配，不是封嘴（坑 1）。

### Phase 2：拆古（前提爆破）

**目标**：拆掉反对意见依赖的"传统/惯例"前提。

**执行工具**：**拆古之钥** / 拆古四步——读 `references/question-keys.md`（钥②）、`references/methodology.md`（方法论二）。

**步骤**：问"你说的'古'是哪个？"→ 列互异个例 → 让权威词失效。

### Phase 3：反证（以子之史反证子）

**目标**：用对方崇奉的先例反打对方。

**执行工具**：**反证之钥**——读 `references/question-keys.md`（钥③）。

**步骤**："你尊崇的那几位，恰恰都破了他们之前的'古'。"

### Phase 4：逼拍板

**目标**：把"不决定"的成本摆出来，逼一个决定。

**执行工具**：折算变体 + 迁行收口——读 `references/methodology.md`。

**步骤**："疑行无成，疑事无功——现在定，还是不定？"**红线**：逼"别拖延"，不是"别思考"（坑 7）。

### Phase 5：落定

**目标**：把决定变成可执行下一步。**步骤**：输出决策 + 第一步。**然后必过 ④ 自省警戒。**

### 形态 ② 拆论（Phase D0→D5）

识别成说 → D1 前提爆破 → D2 对称二难 → D3 矛楯之问 → D4 效率折算 → D5 收口+建设性。详见 `references/sop-interactive.md`。**红线**：D4 不得折算伦理/情感/审美（坑 2）；D5 必须给替代结构（坑 6）。

### 形态 ③ 验证（Phase V0→V5，强护栏）

V0 **正当性三问（不可跳过）**：目的正当？对象有隐瞒动机？手段合法且不侵害权利？任一为否 → 终止。→ V1 挟知而问 → V2 倒言反事 → V3 交叉验证 → V4 边界确认 → V5 产出。详见 `references/sop-interactive.md`。**最强红线**：严禁操纵/诱供/侵害（坑 4、9）。

### 形态 ④ 自省警戒（Phase S0→S5，必过）

判据检查 → **纠错空间检查** → 无辩检查 → 说之难检查 → 产出边界确认。详见 `references/sop-interactive.md`、`references/sop-coach.md`。**这是本流派的警绳，任何形态结束前必过。**

### 收尾：质量自检

**目标**：确保本轮达标（核心是"纠错空间检查"与"操纵红线检查"）。

**执行工具**：逐项过 `assets/quality-checklist.md`（三列格式）。

**步骤**：Must 项未过 → 修复后重检；**警绳项 < 12 分 → 判定不合格**（一票否决）。

## 错误处理

| 异常 | 检测方式 | 处理策略 | 严重性 |
|------|---------|---------|--------|
| 使用目的不正（想操纵/诱供） | V0 正当性自检失败 | 终止验证模式，转正当用途或停止 | 阻断 |
| 拆成虚无（拆掉一切标准） | D5 收口检查 | 强制补"新前提是什么" | 阻断 |
| 想"别争了"（取消辩） | 冲动检测 | 走无辩检查，保留纠错空间（坑 3） | P0阻断 |
| 引用查不到 | 核对 `source-corpus.md` 失败 | 删除引用或修正，禁止杜撰 | P0阻断 |
| 对象无法分类 | 入口路由失败 | 先澄清对象与目的，再路由 | 阻断 |
| 假对称被识破 | 对方指出两命题相容 | 重设计对称（坑 5） | 降级 |
| 折算越界（伦理/情感） | D4 检查 | 换钥，撤回落算（坑 2） | 降级 |
| 轮次过多（>8 轮） | 计数 | 先做一次小结，确认是否继续 | 降级 |

## Gotcha 清单

读全篇见 `references/pitfalls.md`。每一条都附 WHY：

1. **把"取消资格"做成"人身封杀"**——以"没资格"堵嘴。Why：商鞅针对的是讨论前提的错配，不是否定人格与发言权。
2. **只剩"功用"一条尺**——用"有用吗"砍掉礼乐/情感/审美。Why：这是删掉"众人经验"的代价；判据越单一越盲。
3. **取消"辩"=取消纠错（最大警示）**——追求"言无二贵，法不两适"。Why：秦十五年而亡、商鞅车裂、韩非死于狱——结构性的。
4. **故问做成诱供/欺骗**——套话设局。Why：验证模式仅限正当识伪；诱供是从"识伪"堕落为"制造伪"。
5. **假对称**——两命题其实相容。Why：对称之力来自真互斥；硬凑即栽赃。
6. **拆古拆成虚无主义**——拆空一切却不立。Why：拆"古"是为换前提（立法），不是让标准消失。
7. **逼拍板变逼服**——不让对方思考就压决策。Why：商鞅逼的是"别拖延"，不是"别思考"。
8. **"说之难"反讽**——把一切对话当败局算。Why：最懂说之难的人死于说；只算输赢的人最后自己也被算。
9. **验证模式越界审讯/侵权**。Why：这只是认知层面的识伪工具，不是审讯权；越界即违法/违德。

## 经验沉淀（每次运行建议执行）

**目标**：把本次的新发现固化为可复用经验，形成飞轮。Why：本流派的价值随"踩坑库"的厚度增长——跳过沉淀，永远停在出厂水平。

**执行步骤**：
1. 向经验账本**追加**一行（append-only，禁止覆盖历史）：日期 / 形态 / 对象类型 / 结果 / TOP踩坑 / 疑似新坑 / 状态。
2. 检查升格：本次"疑似新坑"若历史累计 ≥2 次 → 写入 `references/pitfalls.md`（附表现+WHY+破解），并在账本标注"已升格"。
3. 无新发现也要记录该行（"疑似新坑"列写"无"）——运行频次是账本的校准数据。

> 经验账本文件：初始不存在时，首次运行按上述表头创建。当前版本账本存放于 `references/pitfalls.md` 文末的"升格记录"处（或由使用者指定路径）。

## 铁律

- ❌ 禁止把"取消资格"做成人身封杀——只针对讨论前提的错配，不否定人格与发言权
- ❌ 禁止取消"辩"、取消纠错空间——**一个取消了"辩"的系统，也就取消了发现自己错了的能力**（本流派最大警示）
- ❌ 禁止把"故问测试"用于操纵、诱供、欺骗取证、侵害权利——仅限正当识伪/尽调
- ❌ 禁止用"有用吗"砍掉伦理、情感、审美——"功用"不是唯一的尺
- ❌ 禁止假对称/稻草人——对称与矛楯必须基于对方真实的互斥命题
- ❌ 禁止只破不立——拆掉前提后必须给出新前提/替代结构
- ❌ 禁止把"逼拍板"做成"逼服"——逼的是"别拖延"，不是"别思考"
- ❌ 禁止引用无法在 `references/source-corpus.md` 溯源的《商君书》《韩非子》内容——杜撰一句即摧毁流派可信度
- ❌ 禁止在未过 ④ 自省警戒（纠错空间检查）前宣布完成——**警绳项 < 12 分即判定不合格（一票否决）**
- ✅ 每条关键约束必须能让 Agent 说出 WHERE（在哪个 Phase 落地）与 WHY（非同义反复的原因）
